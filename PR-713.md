## What changes
- **Versions table**: one row per level/quality, with Clean, Corrupted (and Vaal, when the gem has a Vaal form) prices next to each other, plus how far each row is from your gem. Each price cell is its own item row: hovering shows its tooltip, right-clicking opens the menu, and a click runs one trade search for that version.
- **Vaal chip** on the name row (`vaal-ev.ts`, `VaalChip.vue`): the expected value of using a Vaal Orb on a 20/20 of this gem, measured against selling the clean 20/20. The outcome table shows on hover. It uses the community odds of four outcomes at 25% each, and quality changes by ±1 to 10 up to a cap of 23. A level 19 gem is priced as 20 because it levels back. Missing versions use the best corrupted row below them, or count as 0, and the table says which. It never spends a trade search.
- **Ctrl+Space**: typing "vaal <gem>" gives the same outcome card (`lookups/vaal-gem.ts`).
