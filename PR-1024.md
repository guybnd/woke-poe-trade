Guy asked for a realistic fallback price for every item, for day 1 of a league before poe.ninja has data.

- `scripts/gen-day1-prices.mjs` reads poe.ninja's full-league daily history for each item on every page the filter uses. It takes the middle of the league's first three days and writes `loot-filter/day1-prices.json`.
- `.github/workflows/day1-prices.yml` runs the script by hand (with an optional league) or on a PR that changes it. It commits the table to that branch and starts the branch's tests. This PR's own run fills the table.
- `day1-prices.ts`: the table loads lazily, as its own chunk. `withDay1` adds a line only for names the live snapshot lacks entirely, flagged `day1`. Live prices are still required first; with none, NeverSink decides, as before.
- `PricePoint.day1` is passed through `priceLookup`. Currency, fragments, cards and uniques mark such items est.
- Unit test: `filter-day1-prices.test.ts`.

Until the job runs, the table is empty and nothing changes.
