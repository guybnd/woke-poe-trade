This is a follow-up to #846. Guy asked for a cog on the glance bar when the overlay is open, with the settings inline rather than in the Settings window.

- **Cog:** with the overlay open (and Settings closed), the bar shows a cog. Clicking it opens a popover under the bar with "Bar shows" and a toggle for each field. Changes save as you tick. The popover closes when the overlay closes.
- **No cog while playing:** the bar stays click-through, so there is no cog then.
- **Shared settings block:** the new `GlanceSettings.vue` is now used by both the popover and `ChipSettings` (Settings › Sessions and the dock card).
- **Tests:**
  - A new fake-game test covers opening the cog, ticking a field (the bar and the saved config both follow), and closing the overlay.
  - It also fixes a race in `glance-bar-drag.spec.ts`. The test polled for a saved spot that was already non-null at boot, so it could read the boot spot instead of the dragged one.
