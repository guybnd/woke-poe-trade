## Why
Alt+T stopped working for Guy. The tree key was registered only by the PoB builds widget, and his PoB builds module is switched off, so the key was never registered. That also took away the atlas strategy drawing, which uses the same key.

## What
- The tree key now registers once, from `wokeGlobalShortcuts`, while PoB builds **or** Atlas strategies is on (`treeKeyOf` in `pob-builds/widget.ts`), using the first PoB widget's key. No PoB widget means no key, as before, since Settings lists and clash-checks the key from that widget.
- With Atlas strategies off, the key no longer draws on the atlas tree.
- Settings lists the key as on while Atlas strategies is on, so hotkey clash checks still see it with PoB off.
- With PoB off and no atlas strategy selected, the key says to select one, instead of asking for a PoB build.

## Review
A separate adversarial review found: the key registered without a PoB widget was invisible to Settings and its clash check (fixed: not registered then); the PoB-off note fired with PoB on and no build picked (fixed: checks the module); atlas off still drew the atlas (fixed).
