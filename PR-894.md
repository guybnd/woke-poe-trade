## What
When the Ctrl+Space palette hides, OverlayWindow's exclusive-widget watcher saves the config before the palette's own `watch(open)` adds the recent. Vue runs pre-flush watchers by component uid, so the parent runs first. When the palette closed on blur, or into a tool or Report an issue, no later save followed. The newest recent then stayed in memory only, so a restart or another window's save could lose it.

`remember()` now calls `saveConfig()` when the palette is already closed. It also returns early when the item is already first in Recent, so closing doesn't trigger an extra save.

This is the bug fix only. The redesign of what Ctrl+Space remembers waits for Guy's pick.

## Review
A separate adversarial review confirmed the watcher ordering (Vue 3.5) and found no new bugs. It checked Settings' merge, price check opening, save loops, browser mode and every `remember()` caller. Its one suggestion, skipping the save when nothing changed, is in.
