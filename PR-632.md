WOKEPOET-382. The loot filter stack sizes e2e failed its first try in 58 of 69 CI runs, always on a click that a dock card covered ("`data-dock-row` subtree intercepts pointer events"), and passed on retry in a fresh worker.

Cause: the fake app lives for a whole worker, so the game mouse stays where the previous test left it. When a dock icon appears under it, its hover zone opens the card. `boot()` now puts the mouse back in the middle, where the first test of each worker starts.

The same intercept error shows up about 160 times across the 69 runs' logs (loot filter and Wickerman dock cards), so other flakes may go too. No test moves the mouse before `boot()`.
