WOKEPOET-382, part of WOKEPOET-385. The loot filter stack sizes e2e failed its first try in 58 of 69 CI runs, always on a click that a dock card covered ("`data-dock-row` subtree intercepts pointer events"), and passed on retry in a fresh worker.

Cause: the fake app lives for a whole worker, so the game mouse stays where the previous test left it. When a dock icon appears under it, its hover zone opens the card. `boot()` now puts the mouse back in the middle, where the first test of each worker starts.

The hovered game item leaked the same way: `item-copy-failed.spec.ts` presses Ctrl + D expecting "No item under the mouse", but found the previous test's item. Its first try failed in every one of the 69 runs (about 4.3 s, a 3 s timeout) and the retry passed in a fresh worker. `boot()` now clears the hovered item too.

The same intercept error shows up about 160 times across the 69 runs' logs (loot filter and Wickerman dock cards), so other flakes may go too. No test moves the mouse before `boot()`.
