WOKEPOET-474.

Price check on a Foulborn Kitava's Thirst found no listings. Its trigger line has two numbers ("50% chance ... 200 Life"), the parser averaged them to 125, and the search asked for a 125% chance.

The trade site stores that stat by its first number. I checked each stat on the live trade API rather than assuming one rule, because it isn't one: Death's Oath's "450 Chaos Damage per second for 3 seconds" is stored as the average (226.5 matches, 450 doesn't). So the fix is a short list of verified stats, keyed by trade hash:

- Kitava's Thirst, Mana (stat_723388324) and Foulborn Life (stat_2513998383): 50 matches, 75 and 125 don't
- Tinkerskin's Phasing line (stat_144887967): 30 matches, 17 doesn't
- Deerstalker's Movement Speed line (stat_3102860761): 15 matches, 12 doesn't

Those lines also show both rolled numbers (PoE mode, Standard mode and the source tooltip), so the line reads as in game instead of "50% ... 50 Life".

Guy asked to check the other trigger mods too. I parsed every unique trigger line in the data: the ones above were the only two-number ones; the rest have one number or fixed text. A new test fails if a two-number trigger stat turns up that hasn't been checked.

The "0% BASE" chip on that copy is right: our base percentile for four live Foulborn listings (6, 21, 88, 76) lands in the same bands as the trade site's base percentile filter.
