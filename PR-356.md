_Requested by **Guy**_

Follow-up to #325 (WOKEPOET-154, 3.30 readiness epic WOKEPOET-149).

When upstream Awakened PoE Trade ships new English item or stat data, the hourly copy replaces our files whole. Anything our launch-day patch added that upstream still lacks would be lost. `scripts/upstream-data.mjs` now:
- runs `scripts/trade-data-patch.mjs apply` after copying, when an English file changed and the baseline exists. The patch only adds.
- puts its counts and up to 40 added lines in the PR under "Our trade-site data patch, run again on top".
- notes a failed run (trade site down, or refusing the runner) in the PR, keeps upstream's files as they are, and tells you to run the patch by hand.

Tested locally against a fresh upstream clone with a changed English stats file. The copy, the rerun (0 additions, as expected against the 3.29 lists), the version bump and the PR text all came out right. Everything was then reset.
