- Each of border, background and text colour is a ranked list. The first thing on the list that an item has paints that channel. Steps now set loudness only (size, sound, beam, icon).
- Default order (from Guy's page):
  - Border: over-quality, synthesised, fractured, influence, eldritch, abyss, enchant, 6-link, crucible, strands, 5-link, fated, mirrored.
  - Background: corrupted, then score step.
  - Text: exotic base, then rarity.

- How it compiles: Continue rules per channel. Where the score step paints a channel, the rows ranked above it are worked out per rule. A rule that can't tell is split, with the "has it" version first.
