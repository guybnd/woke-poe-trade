Fixes the red master check: fake-game e2e `map-mods-tabs` › "checking a chart shows the verdict card with its mods" (flaky, WOKEPOET-569).

## Cause
The map check card (`WidgetMapCheck.vue`) loads lazily. An Alt + M that arrives before its chunk has mounted was dropped. The spec presses Alt + M right after boot without waiting for the card (the price-check Alt+M spec waits), so under load it read the hidden, empty card ("That item isn't a map…"). Reproduced locally 3 of 10 runs; instrumenting the card showed no item-text event reached it in the failing runs. PR runs only run scoped specs, which is why PR heads stayed green.

For players: Alt + M in the first second or two after the app starts did nothing. Minor, not data-losing.

## Fix
Same pattern as the early Ctrl+Space press: `index.ts` keeps an item-text for the map check target while the card isn't mounted; the card checks it on mount if under 5 s old.
