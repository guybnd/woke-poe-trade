After signing in through the stash reader, Net worth still said "Not signed in".

**Cause:** GGG removed `/character-window/get-account-name`; it now answers 404 with an HTML page. So the sign-in window never learned who had signed in. The stash endpoint itself still works (200 with the tab list, checked from the signed-in page).

**Fix:** the account name now comes from `/my-account`, whose title is `View Profile - Path of Exile - Name#1234` (or the `og:title` if the title differs). Signed out, that page redirects to the login, which still counts as signed out. Any other page, including the old 404, counts as no answer rather than a sign-out. The request now accepts HTML as well as JSON.

Tests: the name comes from the account page, a redirect means signed out, the old 404 and a login page give no name, title and og:title are both read, and entities are decoded. Existing reader tests now use the profile page.
