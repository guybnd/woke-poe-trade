_Requested by **Guy** · [project thread](https://claude.ai/code/project/chan_01TFAVQEVFL8KKQ8fhVfpfJo?thread=cmsg_01TFAVQEVFL8KKQ8fhVfpfJoBtVw1K7zRdX9yz5ThuXCuH)_

This PR builds Guy's picks A, B and C from the onboarding audit, his note to make Net worth easier to find, and his pick of starter pins.

**A. Welcome card.** The first overlay open after the setup window's first Finish shows a "Getting started" card beside the rail. It lists the price check and search keys, where All tools and Settings are, and Net worth (while it's off) with an "Open in Settings" button. Help and Discord are in its footer.
- Got it, opening a tool from the overlay, or the Net worth button ends it for good.
- It never shows over an exclusive window. Hovering the rail's buttons keeps it up.
- Players who updated never get it, and neither does "Run setup again". Only the first Finish starts it (`tab-bar/welcome.ts`).

**B. Rail labels.** The 3 opens after the card's open name All tools, Settings and Search (with its key) beside the rail's buttons. They also work with the rail flat or on the right. A hover tip hides them.

**C. What's new.** `tab-bar/news.ts` lists tools with something new.
- All tools shows a NEW seal on each one until it's pointed at, and the note shows along the launcher's foot.
- The All tools button counts the unseen ones.
- A fresh install marks them all seen.

**Net worth is easier to find.** While the stash reader is off, All tools lists Net worth as an Off row under Economy. Clicking it opens its switch in Settings › All modules, which still asks first.

**Starter pins.** Until now the rail's default pins only applied to placed windows, so a fresh install's rail was empty.
- The first setup now picks the first 5 switched-on tools from Market, Map mods, Atlas strategies, PoB builds, Trades, Run timer, Lab, Flips, Trade searches, Regex library and Challenges (`pickStarterPins`).
- They show on the rail by type. Nothing is placed or loaded until one is clicked or opened another way, and then it becomes a real pin.
- A picked tool that a fresh config already places (Regex library) is pinned right away.

**Perf.** Startup JS is 1,631 KB, against 1,639 KB on master and a budget of 1,640.
- The card and labels load only while there's first-run help to show (`RailWelcome.vue`).
- The setup window's page no longer ships in the overlay's startup JS (`App.vue` loads `SetupWizard` async).

**Review.** Two separate adversarial reviews; all findings fixed:
- Run setup again restarted the help and cleared What's new.
- The label count was off by one.
- A window opened by a hotkey during play dismissed the card.
- A rail low on the screen pushed Got it off screen.
- After the lazy split, the card blinked out while a rail button was hovered.
- Regex library as a starter pin was hidden, then turned up later as a pin.

**Tests.**
