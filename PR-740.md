Fixes three user-reported bugs in Ctrl+Space search's **Trade site** button. The item menu's Trade button had the same problems and gets the same fix.

- **Listings:** the link now opens the same listings as the price check: Instant buyout while its setting is on (the default), otherwise anyone online. Items sold only through the Currency Exchange (divination cards) open any online seller, as the price check does. Before, it always opened "In person (online)". Megalo's link now uses the same shared helper (`shared/trade-status.ts`).
- **Foulborn:** a plain unique's search leaves out Foulborn copies (`foulborn_item: false`, as the price check sends). A Foulborn unique searches Foulborn copies only.
- **Unique maps (Cortex and the rest):** these sit on the plain `Map` base. The trade site only accepts that base with the `map` discriminator, so the old link found nothing. Name and type now carry it, as the price check sends them. The plain Map base gets the discriminator too.

Tests: unit tests in `item-menu.test.ts`, and a new e2e test in `search.spec.ts` (Mageblood opens with securable status and no Foulborn copies; Cortex opens with the map discriminator). Its scope in `scope.json` is extended. An adversarial review found no bugs; it flagged that the plain Map base was missing its discriminator too, which is now fixed.
