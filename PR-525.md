## What

The loot filter Rules tab's middle column was hard to read. Conditions were cut to "MapTier >= 1…", the preview column was squeezed, and border-only "Deco" rules sat among the real tiers. This replaces it with a ladder view, Guy's pick A from the mockups. It is one generic view for every group, not a screen just for maps.

- **Ladder:** tiers best first, ordered by the one number condition that changes between them (read from the filter: MapTier, Quality, item level…). Readable columns: order, look, what else it needs, Shown/Hidden.
- **Bands:** neighbouring tiers that look the same fold into one row ("T11–13, 3 tiers, same look"). Changing a band changes all its tiers; chips in the side panel pick one tier alone.
- **Marks:** `Continue` rules (NeverSink's Deco borders) leave the list and become chips such as "Black border · T11+" or "Red border · T14+, depends on AreaLevel". Marks that always apply are drawn onto the rows' previews in file order. The others show as "sometimes".
- **Special rules:** rules off the order, plus links to NeverSink's sub-groups (Maps › Influenced…).
- A "Hidden below this line" divider, and a Shown/Hidden button per row ("Off" for commented-out rules).

Stack groups keep their stack column and scale. Groups without a number order (currency…) get the same columns without bands.
