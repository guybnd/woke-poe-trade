## What

**1. League mechanics rail cut off.** In the game look, panels get a 14px scrollbar. The rail always scrolls (17 mechanics), so a fixed 52px column left about 37px for 42px buttons: labels showed 2 letters, icons were clipped, and a sideways scroll appeared. The rail column is now `auto` with `scrollbar-gutter: stable` and `overflow-x: hidden`, so it sizes to the buttons plus the bar (65px in the game look, 59px otherwise). Reproduced before and after in headless Edge with real scrollbars.

**2. Every price read as thin in a new league.** poe.ninja's 7-day graph is null for days before the league started. On day 2 even Chaos Orb had 5 gaps, so `isThin` (3+) was true for all 8,912 items in the live snapshot, and Skip low confidence emptied Delirium orbs, Simulacrum and others. Now:
- `graphGaps(graph, days)` counts gaps only within the days the league has prices for, scaled to 7 days. An item priced only today on day 2 still reads as 4 of 7, so thin.
- `parseDenseChunks` takes the days from the longest history in the feed. The Market window uses `feedDays` (Divine Orb's graph), and price check uses Divine Orb's graph, so every place agrees.
- Tooltips now say "about N of every 7 days" instead of "N of the last 7 days".

Side effect: the loot filter's market retier skipped thin prices, so it barely moved anything in the league's first week. It now uses the early prices.
