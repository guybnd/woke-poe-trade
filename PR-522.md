Guy asked for a new launch toast because the old one looked outdated. He picked B (stone strip) on the [pick page](https://claude.ai/artifact/9UvyUsdH1W2YQWre9Feczc) and asked for a version line under it.

- It sits bottom centre above the skill bar, as before (20vh from the bottom).
- Line 2 names the real overlay key: "Ready · Shift + Space opens the overlay".
- Line 3 shows the running version and then any update news. It reads "Update X downloading", "Update X available", "Update X installs when you quit" or "Up to date", and it changes live if the update check finishes while the toast is up.
- It never takes the mouse, fades in, and leaves after 3 s. The "show overlay ready" setting still turns it off. Text follows the Text size setting.
