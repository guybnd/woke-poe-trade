Each campaign run now saves a timeline you can review afterwards. Ticket WOKEPOET-271. Mocks: https://claude.ai/artifact/QhBzT9EB4qPjFiNYsTGVJL. This builds option C (recommended); Guy's pick is still open.

## What it records
- Every zone entered (area id + name), each level-up of the run's own character, and each of its deaths (`<name> has been slain.`), at run time (pauses left out, same clock as the splits).
- One file per run, `<userData>/woke-docs/run-timeline/<run id>.json`, through the existing `doc-get`/`doc-put`/`doc-delete` ops. Nothing new in config.json except `timelineTrash` (ids of files to delete).
- Size, replayed against Guy's real Client.txt: 22 runs, 10-12 KB per campaign. Runs left open into maps reach ~35 KB, and recording stops at 4,000 steps (~100 KB).
- RAM: only the run being recorded is held in memory. A past run's timeline is read when you open it and dropped when you leave.

## Review view
Run timer › Past runs › click a run: a summary (class/level, date, deaths, town time, run time), a level-over-time chart against the run you race (or the PB), then the time spent in each zone per act, with the number of visits and the gap to the other run's time in the same zone. Racing a run moved from the row click to a "Race this run" button in the review footer. Runs saved before this change show their act splits only.

## Housekeeping
Timeline files of runs that leave history (deleted, pushed past 30, or under a minute) are deleted on the next start, so Undo still finds them.
