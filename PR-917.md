This fixes the three leftovers from #916.

- **OCR map scan:** a rating saved under another wording of a mod's stat now counts, as it does on the map card. Example: "Areas contain a Mirror of Delirium" vs "Area contains…". Only wordings that say the same thing count, so a rating on "increased" never carries over to "reduced". Sibling wordings of rated mods are always compared in full.
- **Net worth run hotkey on an unidentified unique:** it copies as its base, so it used to be priced as a white base.
  - If exactly one unique uses that base, it is now held as that unique.
  - If several do, or none, it is refused with a toast that says why.
  - It is keyed the way the stash counts it: a rolled unique by its base, any other by its name.
- **Settings Undo:** Undo after setting the map check key (which places Map mods) now takes that window back out.
  - It only removes a widget this settings session placed, and only while that id still holds the type that was placed.
  - The list is cleared each time Settings opens.

A separate adversarial review covered all three. Its findings are fixed in the last commit: an id clash could have dropped another tool, a stale id could have carried over between sessions, and the toast was wrong for a base with no known unique.
