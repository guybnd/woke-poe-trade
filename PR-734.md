Typing "settings" in Ctrl+Space found only the web rows: settings pages were matched by their own name only ("Game & league", "Hotkeys"), and there was no entry for the window itself.

## What changes
- `search/settings-index.ts`: settings results for the palette. "settings" (or setting/options/preferences/config, from 4 letters) lists **Open settings** and every page. Other words match page names and old page names, plus each setting by label from the pages' `find` lists (the same index Settings' own Ctrl+F uses). "text size settings" drops the settings word and searches the rest.
- Setting results say their page ("Setting · Game & league") and open it with a new `settings::find=<label>` flag; Settings scrolls to that row and flashes it. The flash now retries for about a second, so pages that load async still get it (also helps Settings' own search).
- No new data or chunk: `pages.ts` was already in the palette's bundle.

- E2e: `testing/e2e/search-settings.spec.ts` (registered in scope.json): "settings" lists Open settings and pages, a page opens; "account name" opens Game & league with the row in view and flashing.
