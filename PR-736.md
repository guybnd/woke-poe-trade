- Ctrl+Space: "Make everything bigger/smaller (UI size)".
- Price check palette: Size −/+ for that window (the existing font size), applied live even while saving waits for the window to close.
- Toolbar cog menu: "Toolbar layout and size" on top, then a separator and "Tools look and size" (theme + UI size −/+). Reset now says "Reset toolbar position and size".
