A 3.30 league module, **Wickerman (3.30)**, with the Viscera facts from wickermanledger.site. It has its own switch in Settings › Modules › Mapping, so it can be turned off or removed when the league ends (remove `woke/wickerman/`, its `modules.ts` entry, the strip in `CheckedItem.vue`, the lookup in `WidgetSearch.vue` and the line in `WidgetCampaign.vue`). Guy's picks from the mocks were A, B and C; the planner (D) is for later, in the PoB section.

- **Price check (A):** pricing a Viscera shows every version (Low / Med / High or a named one), marks the one you hold, and lists who drops it: the campaign boss and zone, plus map, pinnacle, guardian, conqueror and nightmare bosses. Links the site marks as inferred are underlined dotted, with "Not confirmed" on hover.
- **Ctrl+Space (B):** finds Viscera by name, boss, zone, map or effect word ("ignite"). Each card shows the slot, the price, every version and every drop source.
- **Campaign card (C):** lists the Viscera this zone's boss drops, with every version's mods. It matches on zone name and act (from the area id), because zone names repeat in acts 6 to 10.

Data: `public/data/league/viscera.json` (163 Viscera, 66 KB) is fetched on first use and never bundled. It is a live-data shared file (added to `SHARED` and `SHARED_FILES`), and the data version goes to 16. `npm run viscera-data` rebuilds it with a small literal parser that reads the site's script without running it. The site's best-in-slot picks are left out.

The held version comes from matching each implicit number against the versions' ranges, so an advanced copy's `9(8-12)%` works too. When versions overlap, the name settles it: "Lesser X" is Low, "Greater X" is High, and a plain name is Med.

Checks run locally: eslint, `vue-tsc` (app and tests), the full vitest suite (185 files, 4,052 tests), and `vite build`. Startup JS is 1,522 KB against a budget of 1,640 KB; the module code loads in its own small chunks. I also had Claude do an adversarial review; its two real findings are fixed (the README/docs module table, and a plain-named tie that picked Low). Not yet tried in game.
