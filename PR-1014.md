Shared frame for building the rest of the loot filter sections class by class (design picked in the round 1/2 mockups).

## What changes
- **Loot tab**: the beta Currency weights tab is renamed Loot and gets a rail of loot classes (Currency live; Fragments, Cards, Uniques, Gems, Maps, Jewels, League say NeverSink decides them for now).
- **Section modes**: each currency category header has Off / Weighted / Always (`catMode`). Off hides the category, Always shows all of it. An item's own Off (step 0) or Always (supply 1) wins over its section.
- **Alt+F card**: section row (Off/Weighted/Always for the whole category) plus a "This item" row; says "X is off" when the category is off.
- **Faint step** (X1): the bottom step can show under-the-line items as small plain text (size 20, no sound/icon/beam) until a strictness multiplier (default ×1.25, or always). Off by default, so existing filters compile the same. Items set to Off by hand stay hidden.
- New helpers in `currency-weights.ts`: `forcedHidden`, `faintOn`, `faintLook`, `multOf`; settings `catMode`, `faint` (normalized).
