## What

The glance bar (Session story) took the mouse and showed its drag handle ("Glance bar | Tonight N maps" + grip) whenever the overlay was open, so it sat over price checks and trade searches. It now does that only while the Settings window is shown (`wm.active && settings.wmWants === 'show'`). In a map it still shows as the click-through bar, as before.

The after-map toast and big-hit popup don't share this gate (the toast's title bar is always its handle while it's up; the big-hit popup only appears on a hit or via "Place the big-hit popup"), so they're unchanged.
