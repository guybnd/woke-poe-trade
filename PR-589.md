3.30's advanced copy shortens a long option list to `(...)`. On The Dark Monarch, `Maximum number of Summoned Golems(...) is Doubled` / `Cannot have Minions other than Summoned Golems(...) — Unscalable Value` showed as "Not recognized modifier", because our stat only knew the full list `(Animated Weapons-Holy Armaments)`.

- `(...)` is now dropped before stats are matched, along with a space in front of it if there is one. What's left is the stat's plain text, which every advanced matcher is also looked up by.
- 87 random support and random skill gem stats share their plain text with a fixed stat, for example "Socketed Gems are Supported by Level 20 Added Chaos Damage". The matcher index returns the fixed one, so a line with `(...)` first looks for the stat whose advanced form has that plain text. Without this, a folded line would search the wrong trade id.
