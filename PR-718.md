Guy: "why does the number of maps here keep resetting ... it keeps going back to 14" (glance bar, Tonight N maps).

**Cause:** the night being read lived only in memory. On start-up Session story rebuilds it from the game log's tail, which `game-log-tail.ts` caps at 256 KB, about a dozen Fortress maps. Every overlay restart (several dev-build swaps today) rebuilt tonight from those last ~14 maps, so the glance bar, tonight's card and the night's saved summary all lost the earlier part.

**Fix:**
- `store.setLive` also saves the draft (`session-story` collection, key `tonight`) whenever its area count changes (about twice per map), and clears it when the night ends.
- At start, `readDraft()` reads it back before the tail replay (skipped if that night was already saved); the replay already feeds only lines after `draft.lastAt`, and a draft that went quiet past the 15-minute gap ends as a normal night.
- No writes happen before the saved draft has been read, so the skip-list watch at setup can't wipe it.
