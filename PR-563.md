_Requested by **Guy** · [project thread](https://claude.ai/code/project/chan_01TFAVQEVFL8KKQ8fhVfpfJo?thread=cmsg_01TFAVQEVFL8KKQ8fhVfpfJoA43NKqXWifoYTB4Gd8EcWG)_

The loot filter editor froze the overlay for 135-170 ms on every edit, and closing the overlay froze it for another 100-145 ms. This PR makes both cheaper without changing what the editor does.

## What was slow

- Every edit re-parsed the whole NeverSink filter (544 KB, about 12 ms) and then composed it from scratch.
- Half of each rebuild went to gem-name lookups. Every BaseType name in the filter was hashed twice per rebuild to check whether it's a transfigured gem.
- Recording an undo step stringified the whole undo history (about 600 KB on a real config) to check it against its size cap.
- The Preview tab sits in a KeepAlive. While another tab was open, it still re-dropped its loot pile and re-read the comparison filter on every edit.
- On overlay blur, `saveConfig` deep-compared the 1.1 MB config, then stringified it through the reactive proxies (about 44 ms on its own) and parsed it again.

## Changes

- `parse.ts`: `parseFilterCopy` parses each text once (the last two are kept) and hands out copies via `cloneDoc`. Blocks, conditions and actions are new objects, and the source lines are shared because nothing changes them after parsing. Compose and the store's other base-text parses use it.
- `gem-bases.ts`: `gemBaseName` is remembered per loaded item data. The cache resets whenever `ITEM_BY_REF` is replaced.
- `timeline.ts`: each step's size is measured once (WeakMap). The cap is the same as `JSON.stringify(steps).length > 1_000_000`. Saved steps are measured while idle.
- `store.ts`: the timeline and settings copies read the raw config, and the timeline watcher reuses the JSON it already watched.
- `PreviewTab.vue`: while the tab is hidden, the pile and the compare read pause. They refresh when you come back.
- `Config.ts`: saves are compared as text from one raw stringify, which replaces the deep-equal check and the clone.

## Measured

Headless fake-game harness, production builds, Guy's real loot filter config (1.1 MB with history), NeverSink 8.21.0a very strict. Numbers are long-task ms, two runs each:

| step | master | this PR |

| pick Red beam (edit) | 164 / 169 | 87 / 71 |
| toggle 6-socket preset (edit) | 135 / 140 | under 50 / 55 |
| toggle it back (edit) | 168 / 152 | under 50 / under 50 |
| back to game (blur saves config) | 145 / 101 | 67 / 58 |
