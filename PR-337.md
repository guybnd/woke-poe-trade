Replaces the "all JS" ratchet with a fixed target, as Guy chose.

Until now, `bundle.allJs` followed the measured size plus a few KB, so almost every feature had to raise it (4545 → 4700 since Nov 4). It doesn't measure what players feel. The JS loaded at startup costs RAM and start time.

- `bundle.allJs` (every JS file, including ones loaded later): a fixed **5120 KB** (5 MB).
- `bundle.startupJs` stays at 2215 and remains the strict line.
- `WOKE_PERF_UPDATE=1` keeps All JS at 5120 when it rewrites the budgets.
- `perf/README.md` says the target isn't raised per feature.

## Checks
`npm run test:perf` passed locally on master + this change. Startup JS is 2193 / 2215, All JS 4679 / 5120, event listeners 2280 / 2300. Every row passed.
