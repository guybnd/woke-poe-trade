> TL;DR: Guy's eight improvement ideas for the PoB build panel (thread 2026-11-11). Layout changes get mocks first; the hover and dropdown changes are built directly.

1. Next section takes too much space; tree node names aren't hoverable. (A)
2. Links: hover a link group to see the item it sits on in that loadout. (B)
3. Gem and gear set pickers should be tied together, or have a toggle; maybe one connected list. (C)
4. Hovering a gem in Leveling shows where to get it (quest reward or vendor, for the build's class). (D)
5. Next's gear items hoverable; whole Next section collapsible. (A)
6. Own notes in the Notes tab; optionally appended to PoB notes. (E)
7. Trades tab: shortcut to a saved-searches folder linked to the build. (F)
8. Passive tree "Changes from" gets a dropdown to pick what to compare against. (G)

Rules: mocks before building layout changes; comparison views opt-in; RAM budgets (memory.listeners 2300, bundle.allJs 4700).
