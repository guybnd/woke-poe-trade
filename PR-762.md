## What

Follow-up to #761, from Guy's feedback ("Space maybe? ... a small window next to the currency itself ... a setting we can disable").

- A hotkey price check of an exchange item poe.ninja prices (`instantCheck` in `PriceCheckWindow.vue`) renders the new lazy `InstantNinjaCard.vue` next to the cursor instead of the window: price each, stack total, 7-day change, cache age. The mouse is tracked into the card (track-area sent once it's placed, flipped left/up at screen edges).
- Space or Enter (no modifiers) or **Live offers** opens the window with `live` set, so it searches; **Details** opens it without a search (ninja verdict from #761). Esc closes.
- Stacked Decks keep the window (their open-or-sell chip). Checks from inside the overlay still open the window and search.
- Setting `wokeNinjaInstant` (unset = on) under "poe.ninja price first", labelled "Instant price card" and findable from Ctrl+Space.
- e2e: currency spec covers the card, Space, Details and the setting off; window-focused specs boot with the card off; the essence side-window spec clicks Details.
