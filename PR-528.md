## What
Guy couldn't see what a Viscera does in the Wickerman window without clicking a row open.
- Each row now shows the mod of the version for the area level of the last zone you fought in. Towns and hideouts don't count.
- Hovering a row lists every version, with its poe.ninja price where there is one.

Which version drops where isn't published, so the tier is a guess, and the window says so in an (i) note: Lesser in the acts (below 68), plain in maps up to 77, Greater from 78. A Viscera without that version uses the closest one it has.
