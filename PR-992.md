## Why
Guy saved a setup, but it was never kept. The dev build owner checked live memory over CDP and all 20 config backups: the finder's `saved` was `[]` throughout, so the save never happened in memory. In the fake game, Save works with Enter, with a click away, and with a click inside the window. The likely gap is typing that never reaches the name box (the overlay isn't keyboard-focused). The box then blurs empty, and `saveSetup` returns without saving or saying anything.

## What
- The name box starts filled with a name built from the auras and the mod count ("Hatred, Grace · 2 mods"), already selected so typing replaces it. An empty name also falls back to that name.
- A ✓ button next to the box saves without the keyboard.
- `saveConfig()` runs right after a save or a remove, so a restart before the overlay next loses focus can't drop the setup.

## Tests
- `testing/e2e/watchers-eye.spec.ts` gets a new step: Save, then ✓, with no typing, keeps "Hatred, Grace · 2 mods". The full spec passes locally against a fresh `vite build`.
- vue-tsc and eslint pass.
