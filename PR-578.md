## What
- **`shared/price-row.ts`** (pure): `pickRow(rows, variant?, { fallback })` — an item known by name takes the asked variant, else its plain row (a currency's first), else the cheapest variant. `divineRate(live, snapshot)`.
- **`shared/price.ts`**: `usePrice().priceOf(name, { ns, variant })` over live poe.ninja with `pickRow`, plus a rolled unique's unidentified price from a trade quote already on hand (`useUnidPrice`, never searches; searches stay on click). `usePriceText(snapshot)` gives `fmt` and `divine`: live poe.ninja's rate, else the window's saved snapshot's.
- Users:
  - Tooltip (`marketFor`), Search's lookup cards and Boss runs / Analytics (`priceResolver`) all pick rows with `pickRow`.
  - Nine local `fmt()` + `snapshot.divine` copies replaced: Atlas card, loadout and window, Farming (including the divine saved with runs), Scarab flip, Lab gems, League invest (plan math too), Trade, plus Search and the tab bar's divine.

## Behaviour changes (deliberate, so a row and its tooltip agree)
- Tooltip of an item with no plain poe.ninja row now shows its cheapest variant, as Boss runs and Search already did (before: the first variant listed).
- Windows built on the Market snapshot convert to divines with the live rate the tooltip uses, falling back to the snapshot's.

- Loot filter Prices tab keeps its own economy grouping (finding 5 territory).
