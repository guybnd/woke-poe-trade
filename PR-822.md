Guy wants to keep the site's current layout for now, so the chapters layout from the first commit is reverted. What this PR does instead is a modular retake system for the website pictures.

- **Website shots workflow** (`.github/workflows/website-shots.yml`): runs the landing specs on the fake game on GitHub, where poe.ninja and web.poecdn.com load, and commits the new shots and clips back to the branch.
  - Actions > Website shots > Run workflow has one tick box per landing section, plus "changed since the last release" (default on).
  - A push whose commit message says `[shots]` retakes everything.
- **Parts** (`testing/tools/shot-parts.mjs`): maps each landing section to its tests and its app folders. That map is what "changed since the last release" uses.
- **Skip unchanged** (`docs/scripts/keep-same-shots.mjs`): puts back any picture whose pixels barely changed, so only real changes get committed.
- Landing tests take item art from `testing/fixtures/icons` first. With `WOKE_SAVE_ICONS=1`, a missing icon is fetched and kept.
- Specs are fixed for UI changes:
  - search pin now uses Ctrl+P
  - atlas crop
  - filter clip uses "Rank 3"
- This PR also carries the retaken shots and clips from the run.
