## What

3.30 rare-only mods now read as a prefix or suffix, with a Rare-only tag on the price check row. Before, Woke never ported upstream's rare-only support, so these mods counted as neither side and Pre ≤ / Suf ≤ miscounted.

## How

Ports upstream 803d188d (rare-only mods, 9-mod maps) and 38db3e1 (GGG's fixed English text, "Rare-only Prefix Modifier" / "Rare-only Suffix Modifier"):

- `client_strings.js` (4 languages) and `interfaces.ts`: `RARE_ONLY_PREFIX` / `RARE_ONLY_SUFFIX`.
- `advanced-mod-desc.ts`: rare-only lines get `ModifierMechanic.RareOnly` and their side. Russian, Chinese and Korean use one word for both, so the side stays unset there (upstream would call every one a prefix).
- `create-stat-filters.ts`: exact searches keep rare-only stats, as upstream.
- `FilterModifier.vue`, `rareonly.png`, `app_i18n.json`: the tag's icon and name.

Found while reviewing #657, which flags these client strings as not copied.
