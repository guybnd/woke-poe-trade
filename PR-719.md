Bug hunt across today's features, batch 1.

## Fixes
- **Incarnation fights counted as maps.** `MapWorldsMemoryBoss1/2/3` (and `_Uber`) are the 3.30 Incarnation arenas (Fear, Neglect, Dread). They weren't in `boss-areas.ts`, so `isMapArea` took them for maps. They now count as boss fights everywhere (Session story, toast, Map history, Farming, Net worth's map count) and Boss runs knows the arenas. Ids from poedb; Boss3 confirmed in a real Client.txt.
- **Ctrl+Space Map history buttons with Session analytics off.** The tonight and "maps" cards offered Map history / Show, which open Session analytics; with that module off the click ended on "Place that window from the dock first.", which can't help. The buttons now show only while Session analytics is on (the maps card falls back to Open Session story).
- **"N maps in the last 2 days"** on the maps card was wrong: the list is your last 20 maps, whenever. Now "Your last N maps".
