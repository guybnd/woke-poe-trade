Guy's merc thread, option A1 ([mockups](https://claude.ai/artifact/A6ajETUWPTs94s154TKhSX)). Guy picked "live search + local ledger" (no server).

## What changes
- **Support ladder** above a warrant's filters (`renderer/src/web/woke/merc/`, lazy loaded). For each skill it lists the supports, each with a tick box that drives the real search, and what each support adds to the price.
- **Measure** (one click per skill) runs N+1 trade searches: warrants with the skill, then warrants with the skill and one support linked to it. Each search is clean: every other skill group, "not linked" row and the 6-link row is off, and the measured support is forced to Required. The answer is therefore the same whatever else the player ticked.
- **Ledger:** answers are kept in localStorage for 3 days, keyed by league, skill and support tier (Greater searches only Greater). The next warrant with that skill ranks its supports with no searches.
- **Warnings:** every support ticked (one seller's ask), or a ticked support with few or no listings.
- Merc skill rows in the filter list now show the gem tooltip (`v-item-tip`). The new fake-game spec caught them as a tooltip-rule gap.
- A NEWS line and a release note are included.
