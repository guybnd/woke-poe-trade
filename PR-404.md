Fixes WOKEPOET-215: the perf spec's flaky "every module on" run, with DisenchantPanel throwing `reading 'Testleague'` and the main bundle throwing `reading 'pos'`.

## Cause
Main echoes every `save-config` to every page, the saving page included, and `initConfig` swaps the echoed copy in. Since tools load lazily (#359), panels mount after startup. With every module on, the overlay saves at startup (`OverlayWindow.vue:68`, essence scan) while the widgets are still `uninitialized`. The panels then mount and set themselves up in place (anchor, `bought`, and so on), and the echo of that earlier save arrives and replaces their config with the first-run copy. The mounted component, keyed by `wmId`, never runs setup again, so `Widget.vue` reads `anchor.pos` of undefined and Disenchant reads `bought[league]` of undefined.

Players can hit this too: anyone who picks "Everything" in first-run setup takes the same path, and there will be a lot of new installs on 3.30 launch day.

## Fix
- `Config.ts`: a page remembers the contents of each save it sends and drops that echo when it comes back. Echoes from other pages are applied as before. The overlay's own `config-changed` listener (closing Settings) still runs.
- The font size changed in Settings was only applied through the echo, so the skipped echo still applies it.
- `DisenchantPanel.vue`: reads `bought` through `props.config.bought ?? {}` everywhere, not only at setup.
