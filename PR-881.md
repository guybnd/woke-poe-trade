_Requested by **Guy** · [project thread](https://claude.ai/code/project/chan_01TFAVQEVFL8KKQ8fhVfpfJo?thread=cmsg_01TFAVQEVFL8KKQ8fhVfpfJoM4krnSv2qSH7j3trWcTSVJ)_

The trade site can only search a Valdo map's Void mod. This PR has the price check hide the **already-loaded** listings that carry a mod you skip, so it spends no extra trade searches. It builds the recommended options from the [mockup](https://claude.ai/artifact/AcYCHD4amB2MTEK8oWpXS7): A1, skip toggles on the Valdo strip, and B1, skipped listings hidden with a count.

## What changed
- `valdo/skips.ts` (new):
  - Mods are matched as keys, with numbers read as `#` and case ignored. Only a mod's first line is used for its key, but every line of a listing's mods is checked.
  - The skip list is stored on the active Map mods profile, in `valdoSkip`/`valdoKeep`. Each build profile therefore works as its own template.
  - The list fills itself from the profile's "can't run" (`deadly`) ratings. The Void mod is never skipped.
- `ValdoStrip.vue`:
  - Each Valdo mod row gets a Skip / Skipped toggle. A minions line now shares one row with its player mod.
  - A new Skip row shows the skipped mods as chips, dashed when they came from Map mods. Clicking a chip removes it.
  - The row shows "N of M listings hidden".
- `TradeListing.vue`: `fits` now also drops skipped listings, but only for Valdo maps; nothing changes for other items. The foot says how many were hidden, and a hint row appears when skips leave fewer than 5 listings. A check whose results were filtered this way isn't logged under the search's key.
- `widget.ts`: profiles drop non-array `valdoSkip`/`valdoKeep` values when the config loads.
- Adds a NEWS line and a line to `release-next-notes.md`.

## Tests
- Unit tests in `renderer/test/woke/valdo-skips.test.ts`. The full renderer suite passes: 5,495 tests.
- A new fake-game test in `testing/e2e/valdo-map.spec.ts` skips two mods after a search, checks the hidden count and checks that no new search went out. Both Valdo tests pass locally.
- `vue-tsc` and eslint report no problems in the changed files.
- A separate adversarial review found 4 issues, all fixed here: a log-timer race, lastAsks and the log key using different conditions, no hint when most listings are hidden, and no config check for the new fields.

## Open
- Auto-fill only matches the exact wording of a rating. A rating saved under another wording of the same stat isn't picked up.
- On a non-English client, the mod text may not match English listings.
