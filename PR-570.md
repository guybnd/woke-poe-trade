## Why
Ctrl+Space opens Search but pressing it again didn't close it. When a global hotkey fires, main sends key-up for every key in it (so the game isn't left with Ctrl stuck down) and then focuses the overlay. If you're still holding Ctrl, the next Space reaches the overlay with `ctrlKey` false. The palette's own close check wanted "Ctrl+Space", so it never matched (and a space got typed into the box).

## What
- `hotkey-match.ts`: `hotkeyMainKey`, `isModifierCode`, and `isHotkeyTail`, which matches the hotkey's last key pressed bare. That only applies to keys that don't type a letter or digit, so Alt + P with a query starting "p" still types.
- `WidgetSearch.vue`: after opening by hotkey, a bare tap of that key closes the palette on release. This holds while the query is empty and nothing else has been pressed, clicked or pasted. A held key that keeps repeating doesn't close it, and its repeats aren't typed. The flag resets on every open and close, and on a modifier key-up.

## Review
An adversarial review found three problems in the first version, and all are fixed: letter hotkeys closing on the first typed letter, a held hotkey's repeat closing the palette, and the flag leaking into the next open from the tab bar.
