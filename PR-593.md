Guy's report: in the price check side window "Related to Watcher's Eye", clicking "Wild Hellion Alpha" didn't open its price check.

## Cause
A side-window row opens only when the price check can be given that item (`priceCheckInput`). That had cases for uniques, gems, cards and bulk items, but none for **captured beasts** (namespace `CAPTURED_BEAST`), so beast rows were never clickable. This came with #574, not with the item-row work (#576 kept the same rule). The row for the item being checked staying unclickable is as designed.

## Fix
- `priceCheckInput`: a captured beast is checked as the game's copy of one is (a virtual Captured Beast item; the trade search goes by its name, as `create-item-filters` does for a copied beast).
- `infoOf`: a poe.ninja row of type Beast finds its beast, so the item menu's Price works on Market beast rows too.

## Other report (Prices tab "Not moved" tooltips)
Not the same cause: those rows have no `v-item-tip` on master since the Not moved rework (#573). Left to the thread handling it.
