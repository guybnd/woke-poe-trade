_Requested by **Guy**_

Price check now knows which mods a Harvest swap or a Genteel's Ducat can change (WOKEPOET-162, design picked as mock D plus the Flip tab).

## What changes
- A ⇄ on each swappable mod: max resistance, % increased elemental damage, added elemental damage (off by default), resistance (only while its own element is ticked), and attributes through the ducat (off by default). The popover shows the cost per target in lifeforce and chaos, plus buttons for This only, Any, or one picked element.
- A Flip tab next to Results, only for items with a swappable mod. It shows each element's sell price, the swap cost, profit, and listing count. The main price is always the item as it is.
- Nothing searches without a click. Each button is one trade search. The normal price check is unchanged.
- One "Any" search is split by element. A listing counts for an element only when that element's mod meets the searched roll, and listings that fit two elements are dropped. If an element has too few listings, it can be searched on its own (one click, one search).
- A result made with older filters says so and offers to check again.
- Settings, Price check: switch families on or off, and set the highlight limit (20c by default; it never searches).
- Excluded: corrupted, mirrored and unique items; fractured, crafted and implicit mods; mods whose filter value comes from more than one mod; target elements already on the item. When another mod would be hit by the same craft, the popover warns that the game picks one of the two at random.
