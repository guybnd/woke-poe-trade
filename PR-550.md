The other four of the ten loot filter clarity fixes Guy picked (2, 3, 7, 8). The rest are in #547.

**Plain names for NeverSink's tags.** Squashed tags are split into words from a vocabulary of the parts NeverSink builds them from: "exjewelscorrupted" reads "Special jewels corrupted", "topilvl84" "Top item level 84", "rgbsmall1" "RGB small 1". This covers about 330 tags that used to show raw. When a tag can't be split all the way, it stays as it is, so a guess never replaces a name. `filter-tag-words.test.ts` reads every NeverSink fixture filter and fails on any new unnamed tag. The roughly 100 shorthand tags left (r01, maps_a_t14, idaj_caster) are listed in that test.

**Conditions in words.** Rows, hovers, the switch panel and the Alt+F card now word mod lists ("2+ of these mods: …"), cluster passives, influence, socket colours ("Linked: at least 1 red, 1 green, 1 blue") and item size ("2 wide · 2 tall"). The Alt+F card keeps the full mod list so you can see which mod hit.

**Sockets and links by size.** Width and Height are no longer used to order a tier list, so rows read "RGB small 1" and "6 sockets" instead of "height 2" and "height up to 4".

**Example labels.** A rule with no item list previews a real item it can catch: a two-handed axe for "5 links", gloves for "RGB small 1", a unique two-hander for "Special 6 link". Only the class, base, rarity, size and socket conditions are checked, with sockets limited to weapon and armour classes by item size. When no item fits, the preview keeps the class name, as Guy asked.
