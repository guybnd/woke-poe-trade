## What
Atlas strategies can now read `poeplanner.com/atlas-tree/...` links. Import already accepted them (and guide text with them), but the tree said "isn't a pathofexile.com atlas tree link" and couldn't show or edit them.

## How
- `decodeTree` tells the formats apart by the first byte: GGG's u32 big-endian version always starts with 0, poeplanner's u16 little-endian version doesn't.
- poeplanner layout: u16 version, u16 tree version, u8, u16 count + u16 node ids, then a length-prefixed gzip blob (empty in the links seen; not read). Node ids are GGG's, so they map onto our tree data directly.
- poeplanner character-tree links (no `/atlas-tree/`) are refused.
- Variant picks (e.g. Path of Worship's shrine) aren't in the link; you pick them on our tree. The first edit rewrites the strategy as a pathofexile.com link.
