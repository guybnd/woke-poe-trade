WOKEPOET-515, part 1. Measures a farming strategy (e.g. Nightmare maps) from a start point. Design and picks: https://claude.ai/artifact/1Cs44UCaquPPzWZNApGL1y (R1 + S1 + C1 + D2).

**Rule:** run profit = the stash at the end minus the stash at the start, read by read (each read's counted change, so purchases count the same way as in the rest of Net worth). Typed costs only cover what the stash can't see. A typed item's own stash change is left out, so nothing counts twice.

- **Net worth › Runs** (new window tab): name a run and start it from the last read, or click a chart point and pick "Start a run from here". It shows profit, per map, per hour, cost per map, Used up / Came in (item tooltips), and Past runs with their totals.
- **Costs the stash can't see:** a per-map line at your own price (chaos or div), an optional "bought" count that shows how many are left, and once-off costs. A run with the same name as an earlier one starts with that run's cost lines.
- **D2:** while a run is going, the Net worth dock icon shows its profit and glows. The window's summary gets a Run chip.
- **Ctrl+Space:** "run", "strategy" or the run's name shows the live run.
- Maps come from map history (vaults left out).
- Storage: `net-worth/<league>-runs` and the small `<league>-run-glance` doc that the dock and Ctrl+Space read.

Part 2 (next PR): Faustus merchant listings read at Stop (one trade search on your own account), sales tagged "this run" or "before", items held outside the stash, and a hotkey.
