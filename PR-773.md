A player asked how to price check a rare base (Necrotic Armour, life + suppress) but list magic items only, to hunt bases to recombine or fracture. Only magic jewels had a Magic chip.

## What changes
- Non-unique armour, weapons, jewellery, quivers and jewels get a rarity chip beside Corrupted. Clicking it steps through Any (non-unique), Magic and Rare. It looks like the Corrupted chip and takes the rarity's colour. This is Guy's pick A from the mockups.
- With Magic picked, the chip turns amber and its hover says why when more than one prefix or suffix row is ticked. Rows summed from several mods (pseudo totals) are not counted.
- Magic jewels still start on Magic. Exact-mode magic gear starts on Any, which sends the same search as before. Flasks, maps, Heist and other categories keep the old Magic toggle.
- The trade query is unchanged: `type_filters.rarity.option` gets nonunique, magic or rare.

## Tests
- Unit tests: `renderer/test/woke/rarity-chip.test.ts` covers which items get the chip, the steps and the query each step sends, and the clash warning.
- Fake-game tests: `testing/e2e/rarity-chip.spec.ts` covers clicking through the steps and the search each one sends, the amber clash state, and that uniques get no chip.
- Local runs: lint, both type checks, unit tests (1063) and the build pass. The fake-game tests run in CI.
