## What
A guard suite proving presets never hide, silence or un-beam NeverSink's most valuable drops. Plain-words summary: [docs/loot-filter-guard.md](../blob/woke/filter-safety-tests/docs/loot-filter-guard.md).

- Runs the editor's real save path (`compose.ts`, pulled out of `store.ts`) on all 7 NeverSink 8.21.0a strictness levels + Vaal style.
- 16 named drops (Mirror, Divine, Headhunter, Mageblood, Apothecary, tiered t5r1, 6-links, levelling drops...) plus every red-beam rule.
- Setups: each preset alone at its harshest, defaults, all on, all 171 pairs, 200 seeded random mixes; hostile prices (everything else 0.01c).
- Also: byte-for-byte when nothing's on, game load check, round-trip, no prices / thin prices, edits + safety net.
- Runs in about 20 s (about 8 s per file with 2 workers).

## Bugs it found (fixed here)
- **6-socket preset muted 6-links**: its rule sat at the top, so 6-links (and influenced, tiered, top-base 6-socket items) got a silent grey vendor label. It now sits right above NeverSink's own 6-socket tier.
- **Weapons-for-your-build hid levelling 6-links** of other weapon classes (and dimmed rare ones). 5-links, 6-links and 6-sockets are now left alone.
