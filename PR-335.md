## What

A player switched Essence scan on, hovered a MEDS monolith, and nothing showed. Scan mode only starts from the Essence scan panel's hotkey (Alt + E) or its Start button, and that panel only existed after pressing "Add Essence scan" on the module page. With the module on but no panel, there was no hotkey at all.

- The panel is now seeded once at launch (hidden, Alt + E unless that key is taken) when the module is on, the same way the loot filter editor is seeded. Players who already have the module on get it on their next launch.
- Switching the module on from anywhere (settings sidebar, Screen reading, dock menu, a preset) adds the panel if there isn't one, via a watcher in the overlay, so Alt + E works right away.
- Screen reading's empty-keys hint no longer says "open its page once", which never added a panel.

Two settings on the Essence scan page, from Guy's picks of the [start mocks](https://claude.ai/artifact/6JYd6YCus8RZwsjVbrToBX) (C and A):
- **Start in maps** (off by default): scan mode starts when you enter a map (a live Client.txt line, never the start-up replay) and stops in town and hideout. Main owns the auto flag: it never takes the screen from map scan, does nothing with the game in the background, and a stop during start-up wins. A hand stop holds for that map instance. Its cost is named in the setting.
- **Show the dock icon while the scan is off** (in maps only, on by default): a click starts the scan; the card says how it starts.
- Essence scan no longer warms the 3-worker OCR line pool; labels are read on the scan's own worker.

## Memory (dev build, private bytes, main process)
