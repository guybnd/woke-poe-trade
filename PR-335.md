## What

A player switched Essence scan on, hovered a MEDS monolith, and nothing showed. Scan mode only starts from the Essence scan panel's hotkey (Alt + E) or its Start button, and that panel only existed after pressing "Add Essence scan" on the module page. With the module on but no panel, there was no hotkey at all.

- The panel is now seeded once (hidden, Alt + E unless that key is taken) when the module is on, the same way the loot filter editor is seeded. Players who already have the module on get it on their next launch.
- Switching Map scan or Essence scan on in Settings › Screen reading adds its panel if there isn't one, so its key appears in the Keys list right away.
- Screen reading's empty-keys hint no longer says "open its page once", which never added the panel.

Scan mode still has to be started with Alt + E per map. Making that easier to find is a separate UI choice (mocks to follow).
