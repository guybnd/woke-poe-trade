A bug hunt over the whole app: 51 found (most confirmed with a failing test first), 38 fixed here. The rest are behaviour choices waiting on Guy's picks. Every fix has a regression test. Each batch got a separate adversarial review, and a final review covered the follow-ups.

## Net worth
- An unidentified unique that isn't a rolled one is priced as that unique from its art, and keeps its own line in totals, tab values and sales. Identifying it is no longer profit. Old own prices and ignores move over once. Whether the stash API really sends the unique's art for unid items is still **unverified in game**; if it doesn't, the item stays unpriced as before.
- Docs that can't be read (locked by antivirus or sync) are no longer treated as empty and overwritten. Runs, history, chart, listings, left-out lists and cheapest checks use `doc-get-strict`. A gain the gains file missed is saved with the next write.
- Left-out Faustus listings stay out of At Faustus, the stale count, the chart band and the dock. Left-out sales stay out of the hideout Sold tile, Ctrl+Space totals and vs ninja.
- Unnamed map runs no longer mix with crafting sessions (usual, kit).
- A past run whose Client.txt days are gone keeps the time Stop saved.
- Pinned chart point follows the line. Tiny holdings prices no longer read 0.00. Old listings and start times show the day.

## Sessions and game log
- A side area you portal back into from the hideout counts as its map, not hideout time (map log, session, deaths).
- Starfall Crater from a map is not a separate boss fight (per-map costs were charged twice).
- `MapAtlasEncounter*` areas no longer count as new maps (Drop counter, Farming, play time).
- A tool turned on later reads a fresh log tail, not the one cached at startup. The path guard is kept.
- The glance bar's total time stops while AFK.

## Maps
- Stash regex: the influence, conqueror and citadel lines are in the collision list, so the Originator token no longer hits Elder/Shaper maps and Experience no longer hits Veritania's Citadel.
- The map scan can call Elder/Shaper maps Safe.
- The Planner reads T17 "less"/"reduced" wordings (Diluted, of Miring, of Congealment...).
- Ratings cycle back to unrated when saved under another wording (card, strip, death recap). A no-number mod (Mirror of Delirium) is named by its real wording. Ratings carry only to same-sense wordings, so "increased" never counts as "reduced".

## Price check
- No crash when an abyss unique or Voices is missing its socket/passive stat.
- Bound By Destiny casing (rolled-unique list and generator, which now warns on names not in the item data).
- A rare searched with only an added mod gets a price. poe.ninja stops counting at full weight when an added mod is ticked.
- New item search strips Foulborn/Vestigial and uses the trade filters.
- 199.6c with divine at 200 reads "1 div". Card rarity never reads "1 in 1000k".

## Settings, Ctrl+Space, overlay
- Hotkeys page lists the bookmarks, map chip, Net worth listing and run keys (clash check included).
- Setting the map check key before Map mods exists now saves. A placed tool never replaces or loses to one added live.
- Ctrl+Space finds sales and listings typed without apostrophes or accents. The "Valdo map" group is in search settings, with a test that every lookup group is listed.
- The icon row is clamped on screen like pins.
- main `pickActions` dedupes keys whatever the modifier order.

## Trade and other tools
- Finished trades don't come back as open offers after a restart. A trade isn't credited to a buyer in a hideout you left.
- Buying above value shows red.
- Saved deck sessions compute luck against every card.
- Analytics per map divides by maps, and ignores unpriced sessions.
- PoB "Buy a 6 link" titles are no longer Act 6.
- "1 map", not "1 maps".
