Pricing Mortem Morsu from Ctrl+Space search (right-click > Price check) left the window at "Matched: ..." with no listings.

**Cause.** In the Tooltip lines (PoE) layout, `CheckedItem`'s body waits for that layout's code chunk (`v-if="show && (!poeMode || poeOn)"`). On the first auto-searching check after the overlay starts, the search watcher's `nextTick` found no trade listing, dropped the search and never retried. Any unique does it, not only this one. Empty mods and 0 DPS are normal for a unique priced by name.

**Fix.** Remember a search that found no listing and run it when the listing mounts. A new item or a cancelled search clears it, so a later Search never fires twice (found in review).

**Tests.** New e2e `price-check-poe-first.spec.ts` fails before the fix and passes after. Lint, vue-tsc, vitest (3705), build, and the price-check/item-menu/search e2e specs (45) all pass.
