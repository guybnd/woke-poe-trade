Guy asked for a What's new bubble in the dock (the icon row) for players who update. Each feature gets a link to see it and a button to dismiss it, and every agent adds its features to it.

**The dock icon** (`dock/WhatsNew.vue`, id `whats-new`).
- After an update, a gift icon with a count shows in the icon row. Hovering it in game lists each unseen line from `tab-bar/news.ts`: the tool's name and its note.
- With the overlay open, a click keeps the card up. Each line then has:
  - **Show me**: opens the tool's window, placing it first if needed. A tool that's off, or Net worth with its reader off, goes to its switch in Settings › All modules, which still asks first. A line can name a Settings page with `settingsPage` instead.
  - **×**: dismisses that line.
- The card's foot and the icon's right-click menu both have Dismiss all.
- It shares "seen" with the NEW seals in All tools, so dismissing or opening a line clears both.
- A fresh install has seen everything (from PR 814), so the icon never shows there.
- It's loaded only while a line is unseen. Startup JS is 1,632 KB against the 1,640 budget.
- It's in `DOCK_ORDER` after Toolkit, so Settings › Icon row lists it.

**New lines.** Net worth's Listed tab and strategy runs, both already on master with no line until now.

**Making it stick.**
- A new CLAUDE.md section, "Every new feature goes in What's new", says how to write a line.
- `renderer/test/woke/news.test.ts` checks every line: a unique id, a tool, a name, and a note that starts "New: " and is at most 110 characters.
- The e2e specs read `NEWS` instead of counting lines, so adding a line breaks no test.
- A CI check that a feature PR *adds* a line isn't reliable to automate, so the rule lives in CLAUDE.md, project memory and the coordinator's briefs.

**Tests.**
- `testing/e2e/whats-new.spec.ts` is new and added to scope.json. Its 3 tests cover the hover card in game; Show me, dismiss and Dismiss all with the overlay open; and a fresh install showing no icon.
- `welcome`, `dock-menu`, `toolkit`, `tab-rail` and perf pass locally, as do lint, typecheck:test, the dock unit tests and ci-scope.
