**WOKEPOET-309 (idea 9 in the [mocks](https://claude.ai/artifact/CBff6gMLPNJ637Pfbb7RiD)).** Each read of your character is saved as a Path of Building build at `Live/<name>.xml` in the builds folder. It holds:
- class and ascendancy
- passives, with masteries, cluster passives and jewels
- every worn item, in PoB's own item text
- socketed gems, grouped by link

PoB opens it with its own numbers.

How it stays safe:
- Main writes only inside `Live/` (`pob-live-save`), through a temp file.
- It overwrites only a file it wrote itself.
- `treeVersion` is set to the newest tree the installed PoB lists.
- The Live folder is never picked as a build to follow.
- A setting turns the whole thing off.
- The build you picked is never touched.

Checks:
- Typecheck and lint pass.
- vitest `live-pob` passes. It reads the file back through the app's own PoB reader.
- `vite build` passes.
- e2e `pob-builds` passes (14/14).
- An adversarial review against PoB's Lua source found 4 bugs plus small ones, all fixed:
  - the Live file could become the active build
  - a missing classId
  - cluster passives
  - a cached tree version

Not yet opened in PoB itself. Not tried in game.
