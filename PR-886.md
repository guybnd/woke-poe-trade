This PR fixes three bugs Guy reported.

**1. Wrong "Drops from" / "Drops in" on Primal Crystallised Lifeforce**

Upstream's `item-drop.json` mixes real drop groups with groups of items that only go together. #875 read every group's `items` as drops.

poedb confirms these groups are not drops:
- Lifeforce is used only at the Horticrafting bench and has no link to the essences.
- Reflective Oil isn't made from or dropped by the other oils.
- Embers have no link to Ichors.
- Orb of Conflict drops only from The Maven.
- Perfect Forest Tiger is an Azmeri corpse, not a drop of the King in the Mists.

`realDrops(group)` in `related-family/recipe.ts` now leaves out these groups' items:
- corrupted essences
- lifeforce
- oils
- Embers
- Ichors
- Timeless splinters, which are a recipe the splinter section already shows

It also drops that one Tiger item. The other members of each group still show under "Related to".

Every other currency group was checked and is a real boss or fragment drop.

**2. Tooltip showed raw "[Enshroud|Enshrouds] Unique Body Armours"**

`parseMarkup` now turns the game's `[Keyword|Shown]` and `[Keyword]` links into their shown text, for every item. The tip data build strips them too, and I fixed the 13 items in `items.json` that had them.

**3. Tooltip showed only a name and price for Allflame Ember of the Multitude**

RePoE has no text for 31 newer currency items, including:
- the 3 newest Allflame Embers
- Threads
- Astrolabes
- Soul Cores
- Facetor's Lens
- Originator's Exalted Orb

I copied their effect and usage lines from poedb into `scripts/tip-items-extra.json`. The next `npm run tip-data` merges them, and the build now logs any currency still without text. A unit test fails if any currency item has no tooltip text.

**Tests**
- `related-recipe.test.ts` and `item-tip.test.ts` have new cases.
- vue-tsc and eslint pass.
- These are bug fixes, so there is no NEWS line.
