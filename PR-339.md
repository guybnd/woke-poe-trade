Players can now opt in to the stash reader (#336), hidden like Android developer settings. Picks from the mockups: P3 (row in the module list), W2 (confirm plus warning box), R1 (takes effect right away).

## What changes
- **Hidden unlock.** In Settings › Modules, clicking the Economy heading 5 times within 3 s shows a toast, "Experimental settings unlocked", and a **Net worth** row with an EXP tag under Economy. The unlock is kept by main in `apt-data/woke-app.json`, so it also lasts in dev mode. **Hide experimental** puts the row away again and turns the reader off.
- **Confirm and warning.** Turning it on first asks "Turn on the stash reader?" (Cancel / Turn on). While it's on, a warning box and the pathofexile.com sign-in show under the row.
- **On and off at runtime.** On: main registers the reader's handlers and the Client.txt hideout hook. The overlay loads the net-worth chunk and adds the module, a hidden widget (dock icon), the settings page, the editor and the hotkey. Off: main signs out (removes POESESSID), stops any read under way, closes the sign-in window and unhooks the log. The overlay removes everything; a placed widget stays in config but counts as off. `personal.flag` still forces it on, and then the switch is disabled.
- **Nothing for everyone else.** Players who never unlock or turn it on load no reader code and get no handlers or listeners. The row, the switch logic and the unlock handler are all lazy chunks. Startup JS is 2214.9 KB (budget 2215, master 2213.6).
- **Fix.** The reader registered `stash-read`, which replaced the OCR stash read that Flips uses. It's now `stash-reader-read`, and reader ops can't take the name of an always-on handler.
- README and SECURITY now say what the opt-in reads.
