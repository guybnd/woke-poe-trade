Part 5 of the deep audit: long-lived bugs that silently lose or corrupt saved data. Four hunters (persistence lifecycle, time, files/main process, renderer state), then a separate adversarial review of the fixes; its findings are fixed here too.

## Fixes
- **Price check history reset every start.** `price-log.ts` reads at module load, before `Host.init()` connects, so `hostRequest` threw, the non-strict read became `[]`, and the first check wrote over the whole log. `hostRequest` now waits for the connection when asked before it (stays synchronous once connected, so quit-flush ordering is unchanged). Price log reads strictly and retries.
- **`writeAtomic`** now fsyncs and retries a rename that antivirus blocks (EPERM/EBUSY/EACCES); `renameRetrying` moved from loot-filter into `data-files.ts`.
- **Strict reads before read-change-write** (an unreadable file is never rewritten with near-nothing): sales merge (`trade-history`, now throws instead of answering with no sales), stash tab picks (`tab-choice`), price log, league-invest import marker, campaign run timeline recorder (retries while the run is current), session story nights (re-read and saved when it recovers) and the tonight draft, market day files.
- Session store reads again after an unreadable file, and patches a newer cache after a write.
- AI link key isn't regenerated over a key file that's only locked.
- Death recap and run timeline saves flush on quit; main waits on the death recap write queue.
- Farming keeps an ended session whose save failed (`config.unsaved`) and saves it on the next mount, unless the file has it.
- Offers marked Traded are pruned from offer history after the replay window (they were never shown and grew forever).
- Map history's 7 days step calendar days (DST gave a day twice / skipped one).
- A map re-entered after midnight is saved on its first visit's day; run summary prefers the merged recent copy on a tie.
- Market saves read only the days they write instead of caching every day of every league in main for the whole run.
- `safeName('..')` → `_`.
