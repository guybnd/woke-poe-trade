## What
Price checking a fractured item now starts with only the fractured mod row(s) and the base type ticked. Every other mod, pseudo total and property (Energy Shield, pDPS) starts unticked and can still be ticked by hand.

- `untickBesideFractured` runs last in `finalFilterTweaks`; a fractured cluster jewel keeps its enchant and "Adds # Passive Skills", which are its base.
- `tickTopTierMods` skips fractured items, so the old "leading rows count toward the cap" code is gone.
- Golden trade queries: only the three fractured fixtures change (`rare-fractured` loses its pDPS tick, the ring and shield lose their extra mod ticks).
