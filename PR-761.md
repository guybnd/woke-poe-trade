## What

Price checking currency and other exchange items that poe.ninja prices exactly now shows poe.ninja's cached price as the verdict and spends no exchange search until you click **Check live offers** (or Enter in PoE mode). Design A from the mockups: https://claude.ai/artifact/RzCo6AUkASKWzLAABZuVtp

- `CheckedItem.vue`: after the usual auto-search decision, `holdBulkSearch` (new `woke/price-insight/ninja-first.ts`) turns it off for bulk-API items with an exact poe.ninja price. Improved view shows the new lazy `NinjaVerdict.vue` in the verdict slot (each, stack total, 7-day change, cache age); the name-row chip and the open ninja card are hidden while it shows. Classic view just skips the auto search.
- Checks started from inside the overlay (`dispatchPriceCheck`: menus' Price check, Ctrl+Space) set a new `live` flag on `item-text` and still search right away.
- `exactDetailsId` in `getDetailsId.ts`: the poe.ninja row for the exact item (no rares' bases, no map tiers).
- After a live search, `BulkVerdict` adds "poe.ninja Nc each · live is N% under it".
- Setting `wokeNinjaFirst` (unset = on) in Settings › Price check, labelled "poe.ninja price first", in the page's find list so Ctrl+Space search finds it.
- e2e: currency specs click Check live offers; the currency spec asserts no exchange request before the click.
