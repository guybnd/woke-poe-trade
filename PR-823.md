Guy asked that each "Show me" in What's new opens the exact tab the line is about, not just the tool.

**How it works.**
- `tab-bar/goto-targets.ts` lists the tabs Show me can open for each tool, by the label each tab shows:
  - Net worth: Holdings, Sales, Listed, Runs.
  - Map mods: Maps, Heist, Charts, Planner, Scan.
- The tools' own tab labels now come from that list, so a line's target and its tab can't drift apart.
- Each `NEWS` line names its tab with `goto`. Show me records the request with `requestGoto(wmId, tab)`.
- `useGoto` (tab-bar/goto.ts) in the tool opens that tab. It works whether the request arrives before the window mounts or while the window is up.
  - The request isn't kept in the window's flags, because a new window's first mount resets them. The first try with flags failed for exactly that reason, and the e2e caught it.
  - `useGoto` is typed so that every tab in the list needs a handler.
- **Lines:**
  - Net worth: holdings, Listed and Runs.
  - Map mods: Planner.
  - Faustus box (added on master since PR 817): holdings. The box sits on the summary line.
  - Atlas strategies: no tabs, so its Show me opens the window as before.

**Tests that fail when a target doesn't resolve.**
- `news.test.ts`: every line's `goto` is a real tab of its tool, and a tool that has tabs in the list must name one. It caught the Faustus box line, which had none.
- `goto.test.ts`: a request made before mount and one made while the window is up each open their tab once, and one window's request doesn't reach another.
- `whats-new.spec.ts` (fake game): for each line whose tool opens without the stash reader, clicking Show me lands on its tab, selected. It reads `NEWS`, so new lines are covered automatically.
- **Not covered here:** Net worth's lines aren't clicked through in the fake game, because there the reader is off and they go to its switch in Settings. Net worth's side is covered by the typed handlers and by `goto.test.ts`.

CLAUDE.md's What's new section now asks for `goto`, and says how to add a tab that isn't in the list yet.
