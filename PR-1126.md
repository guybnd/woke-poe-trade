Guy's Loot price audit (picks: flasks A, no price B, Chronicle A, relics A, influenced A). The audit checked all 1,936 est. Loot rows against live Covens poe.ninja data.

- **Flasks**: poe.ninja's dense `Flask` page prices white bases at item level 82/83/84+. The white top-flask row is now four rows (Divine Life, Eternal Life, Hallowed Hybrid, Divine/Eternal Mana), each priced at its cheapest solid line. Divine Life used to be hidden at a 0.1c guess and is now 9c. The quality rows use their cheapest base as an est. floor, with a "quality not counted" note (`why`). The 30% row never goes below its 5c guess.
- **Chronicle of Atzoatl**: poe.ninja lists temples by room, so the name lookup always missed. The row is now priced at the cheapest solid room line (`TEMPLE_ROOMS`): 50–60c, where the guess was 3c.
- **Relics**: `priceFinder` no longer skips `Relic` variants on the `UniqueRelic` page. Relic bases now use this league's prices instead of last league's.
- **No price**: an item with no price now or last league gets `none` and shows "no price" instead of 0.3c. It is still free, so it always shows.
- **Retired** (no Loot row; the fallback rule still shows them): Harbinger orbs and shards, vials, scouting reports, sized Expedition artifacts, recombinators, power cores, coffins, wisps, and the retired Delirium orbs (the same list as scarab-flip). Breachstones and Maven's Invitations stay as "no price" because I'm not sure they've stopped dropping.
