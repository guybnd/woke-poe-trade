Tooltip audit picks G1 and G3: fills the item tooltips that showed nothing but a name.

## What changes
- **Base implicits, flasks, tinctures** (new `tips/base-extras.json`, from Path of Building's `src/Data/Bases/*.lua` via `npm run base-extras`). Rings, amulets, belts, quivers, weapons and armour show their implicit. Flasks show recovery, duration, charges and effect (the effect sits under the charges, as in game). Tinctures show mana burn and cooldown.
  - Hidden legacy bases are skipped, so the 6 quivers that share a name with an old base show the current implicit.
  - Names that several bases share (Two-Stone Ring, Shadowed Ring, the two talismans) get no implicit, because the name alone can't say which one it is.
- **18 uniques poe.ninja doesn't list** (new `tips/unique-extras.json`, from PoB's `src/Data/Uniques/*.lua` via `npm run unique-extras`). Corpse Rose, Hide of the Vendigo, The Utmost and others now show their mods.
  - Patch versions keep the current one.
  - Pick-one uniques (String of Servitude, Glimpse of Chaos, The Covetous Dark) show only the lines every copy has, and keep each copy as a named variant.
  - The price check and Search read these too (`loadTipUniques` merges them).
- **19 fragment texts**: Shaper guardian, Mortal, Sacrifice, the 4 invitations, Zorath's Eyes and the Expedition Logbook.
- Both new files are shared data files. Item data version goes to 33.
