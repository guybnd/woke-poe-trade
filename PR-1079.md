Master's startup JS was 1640.06 KB against a 1640 KB budget, so every open PR failed the perf check. With this PR it measures 1542.3 KB locally, which frees about 98 KB.

**Cause:** I traced the startup chunk back to its source files with its sourcemap. `vuedraggable` (51 KB) and `sortablejs` (44 KB) were loaded at startup, because `WidgetImageStrip.vue` imports them statically and the widget registry imports that component.

**Change:** the drag container is now `defineAsyncComponent(() => import('vuedraggable'))`, so it only loads when an image strip renders. The other users (the atlas, regex library and trade searches editors) were already async.
