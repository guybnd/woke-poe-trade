Takes over #404 by @bezrq (their commit is kept as-is and credited) and adds one fix on top.

## From #404
Main broadcasts every `save-config` back to every page, the sender included, and the sender swapped that copy in. Panels mount lazily (#359), so a panel that set itself up after a startup save got reset by that save's echo. With every module on, this crashed Widget.vue (`anchor.pos`) and DisenchantPanel (`bought[league]`). Now a page remembers the saves it sent and skips their echoes, and the font size is still applied when an echo is skipped. DisenchantPanel also reads `bought` with a fallback everywhere it's used.

## Added here
- **Race:** if another page's save is broadcast between our save and its echo, we took that page's older config and then skipped our own echo. That lost our changes in memory, even though the disk held them. A save from another page now clears the list of our saves in flight, so our later echoes apply as they did before.
- Unit test `test/woke/config-echo.test.ts`. Its race case fails without the fix.
- The SetupWizard comment that said "every save comes back" is updated.
