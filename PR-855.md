## What
Every published release posts to the Discord announcements channel as an embed: "Woke PoE Trade 1.330.19 is out" (links to the release), the release notes (without the GitHub-only install how-to and SmartScreen line, `##` headings as bold lines, cut at a line with a "full notes" link if over 4096 chars), and a Download field with Installer · Portable · Release page. App icon thumbnail, SmartScreen hint in the footer, no pings unless set.

- `scripts/discord-release.mjs`: fetches the release, builds and sends the post. Drafts and pre-releases are skipped. No secret = prints the post only. `--dry-run` prints it.
- `.github/workflows/discord-release.yml`: runs on `release: released` (a draft published by hand on GitHub) or by hand with a tag (repost / dry run).
- `release.yml`: new `announce` job after `windows` dispatches it when the run publishes (a GITHUB_TOKEN publish fires no release event, so there's exactly one post). Own job so `actions: write` stays off the build; a failure only warns.
- DEVELOPING.md "Discord announcements": the one-time setup (webhook + `DISCORD_WEBHOOK_URL` secret, optional `DISCORD_RELEASE_PING` variable).

## Setup Guy does once
1. Discord: announcements channel › Edit Channel › Integrations › Webhooks › New Webhook › Copy Webhook URL.
2. GitHub: Settings › Secrets and variables › Actions › New repository secret `DISCORD_WEBHOOK_URL`.
