## What
- New `ui/pointer-drag.ts` `followPointer(move, end)`. It ends a drag on pointerup, pointercancel, window blur, or a move with no button held, and returns a stop function for unmount.
- Pins (`PinFrame.vue`) already handled these cases by hand and now use the helper, with no change in behaviour.
- The dock (`Dock.vue`) and the Settings window's resize edges (`SettingsShell.vue`) only listened for pointerup. If the game took the mouse back mid-drag, the dock kept following the cursor when it came back over the overlay, until the next click. Both now end like pins do.
