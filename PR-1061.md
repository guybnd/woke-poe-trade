NeverSink retirement M1, part 2.

- `own-lists.ts`: the Loot tab's currency, fragment and card rows come from `item-lists.json` (game data, #1057) instead of NeverSink's BaseType lists. An item gets a row while it still drops: poe.ninja prices it now, it had a price last league, or it's an odd unpriced item (Facetor's Lens, Scrying Orb, Albino Rhoa Feather). Scarabs and other retired items get no row. With no prices at all, it keeps NeverSink's lists. Both tables load lazily.
- Until the guesses table has been filled once, an unpriced item the base filter lists also keeps its row, so nothing drops off the tab in the meantime. The fake-game Loot test caught this with invitations.
- Guesses: `gen-day1-prices.mjs` now also writes `item-guesses.json`, the league's median price per item with the first three days left out. An unpriced or thin item is guessed from that instead of NeverSink's tier. The table is empty until the Day-1 job runs again.
- Fix: resonators get their real class (Delve Stackable Socketable Currency). Before, NeverSink's two-class fossil rule collapsed to Stackable Currency, so the Loot rules never matched them.
- The dropUnknownBases guard is unchanged.
- Test: against NeverSink's real filter, every priced item it lists gets a row in the same section and class. Only Eternal Orb and Imprint aren't in the released game data.
- NEWS line (Show me flashes the Orbs section) and a release-next-notes line. Two expired What's new lines are taken out, because startup JS was 0.1 KB over budget.
