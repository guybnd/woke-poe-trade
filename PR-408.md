## What changes

- **Tree overlay (WOKEPOET-221):** the passive tree drawing now follows a left-drag only when the press lands on the game window, not on another monitor. uiohook and the game window's bounds are both physical pixels on Windows (same comparison map-scan and Shortcuts already make), so no DPI conversion is needed. New `insideGame` helper with tests.
- **Typed overlay requests (WOKEPOET-178):** `ipc/woke-ops.ts` maps every `woke-request` op to its args and result. `hostRequest` and main's handler table (including the setup, store, screen-reader and stash-reader ops) are typed from it, so a wrong op name or argument shape fails typecheck. No behaviour change. Large records the overlay owns stay `unknown` and are cast at the call site, as before.
- **SmartScreen note (WOKEPOET-260):** README, the docs download page, the landing page hero and every release's notes say "More info > Run anyway". The landing line is hidden on phones.
