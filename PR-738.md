## What

Map scan is folded into Map mods (WOKEPOET-458, from Guy's tool audit). One tool instead of two.

- **Scan box** in the Map mods window's right column, Maps tab only: Scan/Stop, Roll, the safe/risky/dangerous tally, the last 8 maps (each row's hover card lists the mods that decided it) and an undoable clear.
- **Dock icon, on-screen badge and markers** are unchanged, now mounted by the first Map mods window (`MapScanLayer.vue`). Shared live state is in `scan-session.ts`.
- **Keys**: `scanHotkey`, `scanRollHotkey`, `scanAlertOnPass` on the Map mods widget, edited in Settings › Map mods and listed on Settings › Screen reading and Hotkeys. Only the first Map mods window registers them.
- **Retired**: `map-scan` moves to `RETIRED_MODULES` (off the grid, dock list, Ctrl+Space, presets, settings). Its saved window stays in config, unmounted.
- **One-time fix-up** (`foldMapScan`, woke config version 4): copies Map scan's keys and reroll alert to Map mods (making a Map mods window if there wasn't one, and turning Map mods on), moves no keys from a switched-off Map scan, and repoints its rail pin.
- **Ctrl+Space**: "map scan" finds Map mods (tool alias) plus "Map scan on or off" and a new "Map scan: rolling mode on or off" command.
