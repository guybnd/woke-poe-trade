Unique price checks now show how high each line rolled, so a high-roll copy stands out from the average one poe.ninja prices (WOKEPOET-420, Guy's pick C from the mocks).

- PoE mode lines carry each number's range the way the game's Alt view does: `42(30-46)% increased Critical Strike Chance`. When the line rolled in the top tenth of its range, its numbers turn gold. Lines with no range, totals of several mods, flipped "reduced" lines and catalyst-scaled lines show no ranges.
- A **High roll N%** chip sits on the name row when two or more rolling lines average 75% or more up their ranges. Clicking it ticks those lines with a window around this copy's rolls and runs one trade search. Nothing searches without the click. The chip skips hidden rows such as the base implicit, and it skips mods already counted in a total.
- The parser now keeps each number's own range (`roll.ranges`). The display code loads with PoE mode, and the chip is an async component for uniques only, so startup JS stays inside its budget.

Tested in `renderer/test/woke/unique-roll.test.ts`. Guy tried it on the dev build and it looked right to him.
