## What
- **Stop does one final stash read first**, so drops since the last read count. The run then ends at that read, or at the press if the read fails or isn't counted. The button reads "Reading stash…" while it runs, and the read waits up to 90 s.
- **Summary tab on a stopped run** (Runs view, loaded lazily). It opens on Stop, and every past run has a Summary / Details toggle. It shows:
  - per map, per hour and cost a map against your other runs with the same name
  - your best drops, with item art and the item tooltip
  - each map's time, with deaths marked (from Client.txt map history)
  - spent against kept
  - up to 3 tips (`run-summary.ts`), each shown only when the numbers clear a bar: pace, slow maps, a map's cost vs usual, hideout share, and with vs without a kit line (needs 3+ runs on each side)
- **Stop from the dock card** opens the window only when you're in hideout or town. In a map you get a toast, and the summary waits in the Runs tab.
- **Ctrl+Space "last run"** shows the last finished run's summary and tips (`${league}-run-last`).
- One `news.ts` line and one `release-next-notes.md` line.
