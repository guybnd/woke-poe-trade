WOKEPOET-97: the dev launcher (`scripts/woke-dev.ps1`).

- **`Stop-Dev` stops leftover launchers.** It now also finds every `cmd.exe` launcher that `Start-Dev` made. They're matched by their redirect into `.woke-dev\main.log` or `vite.log`, which no other process uses. It stops each one's process tree, `node build\script.mjs` included, even when `main.pid` points somewhere else. On 2026-11-05 such a leftover kept `main.log` open, and the next start failed.
- **A clearer error.** When the app doesn't start and an older launcher still holds `main.log`, the error now says so and tells you to run `woke-dev stop`. Before, it suggested the single-instance lock.

Checked: the script parses with PowerShell's parser. A read-only run of the new match on GUY-PC lists exactly the two live launchers, Vite and main. After merging, copy the script to `E:\Git\woke-dev.ps1`.
