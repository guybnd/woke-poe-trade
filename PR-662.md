## What

Map mods page (WOKEPOET-404):

- **Every map mod now gets a stash search token.** The page showed "No unique text found for: Buffs on Players expire #% faster". Tokens were plain text between the rolled numbers, so 30 of 309 map mods had none: faster/slower wordings, "#% Pack Size" inside "#% increased Pack size", singular/plural pairs, and "Monsters have #% increased Area of Effect" against the boss line. Tokens can now cross the number (`[+-]?\d+`, sign allowed because the stat data drops the `+` the game shows) and pin to a line's start or end (`^`/`$`, the same approach poe.re uses). Heist and Charts had no gaps.
- **Stash search sits above Rewards** (juice scoring) in the right pane.
- **Save can overwrite.** An arrow next to the name lists the tab's saved searches. Picking one, or typing its name, turns Save into Overwrite. The entry's notes, folder and hotkey stay.
- The search builder moves from `data.ts` into `search.ts`, so the map check card no longer pulls it into the startup bundle (startup JS 1640.5 → 1636.7 KB).
