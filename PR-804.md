Guy's hypostasis.faith atlas link (`#t=…`) wouldn't import. Its short code lists no ids. It's one bit per node of a breadth-first walk from the start (neighbours by id), each taken typed notable followed by its pick, behind a 24-bit FNV-1a checksum of the selection; the site's share.js documents this. The walk only reads against the tree itself. Their graph matches GGG's: the same 1050 links, the same start and the same type order.

- `atlas/hypostasis.ts`: decodes the short form against the loaded atlas model (checksum must match), plus the long `#s=id,id:choice` form, and outputs a pathofexile.com link.
- `AtlasWindow.vue` import: hypostasis links in the pasted text become GGG links before the usual import. Unreadable links and data still loading get clear errors.
- The test fixture export gains the notables' type ids. Tests: Guy's link decodes to a tree joined to the start and round-trips through `decodeTree`; cut-short or changed codes are refused; long form with picks; links inside guide text.
