## What

Saving failed with "Woke > Gear > R1-t5: Class has no values (and 5 more)" once every slot of a Base types row had its own line. The row's leftover rule (for slots without a line of their own) was written with an empty `Class ==` list. The save check refused it, so nothing reached the game.

## How

`withClasses` in `gear.ts` returns no rule when no classes are left, so the row writes only its five slot rules.
