Maps where you stepped into a Mirage now get a **Mirage** chip on the after-map toast, in map history and in Ctrl+Space search (WOKEPOET-432).

Entering a Mirage reloads the same map instance (same area id and seed), so the only sign is the loading screen line, e.g. `[INFO Client 41328] [LOADING SCREEN] (Mirage of Fortress) Duration = 1.75 seconds`. Checked against a real Client.txt (11 Mirage entries over two days, every one between two plain `(Fortress)` loads of the same seed). Player chat quoting the text can't match, since the pattern needs the line to start right after the `[INFO Client N]` tag. A Mirage you skip writes nothing, so it can't be shown.
