Flips, raised for 3.30 (WOKEPOET-155, from Guy's tool audit).

## What changes
- **Scarabs tab removed.** Scarabs left the game; poe.ninja's Scarab feed is empty. The scarab weights file goes. The stash reader still recognises the old Scarab tab, so pressing the outline key there now says scarabs left the game instead of drawing scarab advice. (Retiring the main-process scarab layout is left for when a 3.30 Fragment tab screenshot exists.)
- **Threads tab.** 3.30.0c added a Thread vendor recipe; taken as 3 in, 1 of a different type (like the scarab one), pending Guy's check. No one has measured weights, so every Thread is equally likely: rows are marked EST, the tab shows a low-confidence warning, and it stays out of the dock card's best flip. Your own weights in Settings work as for other families. A line says what a Frayed Thread opens to (the plain average), since poe.ninja has no Frayed price.
- **Delirium.** Weights cut to poewiki's 11 drop-enabled orbs; Threaded (renamed Skittering) keeps Skittering's weight; drop-disabled orbs are kept out of the family so Standard prices can't put them in the pool.
- **Catalysts.** Sinistral and Dextral (now priced) can't come out of a recipe or reroll; left out like Tainted, so the footer no longer says "2 with no weight left out".
- **Ctrl+Space.** A flippable item shows its profit per item for each method (with the panel's own discount, reroll and weights), and "flips" shows the best flip. Vendor recipes: Thread recipe added, the removed 3-maps-for-a-higher-tier recipe dropped.
