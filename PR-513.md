## What broke

PoE refused the whole saved filter: `Line 331: Unable to parse parameter for BaseType rule: No base types found exactly matching "Dual Strike of Ambidexterity"`. Filters only know a transfigured gem by its base gem (NeverSink itself uses `TransfiguredGem True`), but the "gems in your build" rule copied the full name from PoB.

## Fix

- `gem-bases.ts`: `renameBases` moves transfigured gems out of any BaseType list into a copy of the rule, placed just before it, that names them by their base gem (game data's `normalVariant`) with `TransfiguredGem True`. Plain names stay in the original rule, so a rule for one transfigured gem never widens to the plain gem. A rule that is already `TransfiguredGem True` is renamed in place; `TransfiguredGem False` drops the names. `composeFilter` runs it before the safety net reads the rules and again last, over every rule, so no writer can bring the name back.
- Preview: `ItemFacts.filterBase` carries the base gem, and the matcher uses it for BaseType, so the card shows what the game will do with a transfigured gem.

## Also: safety net note opened onto an empty list

The dock note said "Safety net shows 35 valuable items the filter hides", but all 35 were small currency stacks (`bases.stacks`), which the Prices list doesn't show. `composeFilter` now returns `netStackCount`; the note counts items only, and the Prices tab says "N hidden items and M small stacks caught right now". Checked live on the dev overlay: 35 caught, 35 stacks, no note.

## Also: "NeverSink 8.20.2 found (you last saved against 8.21.0a)"

8.20.2 is NeverSink's previous release (Oct 15); 8.21.0a (Nov 13) is the latest. The editor only loads 8.20.2 after an Undo of the update, and that Undo was reachable by any Ctrl+Z in the overlay for 5 s (OverlayLayer `undoToast()`, and the editor's Ctrl+Z defers to undo toasts). The update toast's Undo is now button-only (`clickOnly`), and a version older than the one last saved gets its own banner with "Back to <version>" instead of calling it an update. **Real cause (found after Guy's repro):** picking "NeverSink (woke)" from the file list opened our own output as a local source, and `load()` took its original from `NeverSink (woke).filter.bak`, an 8.20.2 file left by an overwrite-mode save on 6 Nov. A woke copy whose header says "downloaded from GitHub" now switches back to GitHub mode instead (test in `filter-flows.test.ts`). The Ctrl+Z change stays as a guard.

## Review

Adversarial review found the first version widened rules (a Hide pinned on one transfigured gem would hide every Dual Strike); fixed by the split above. Known limit: the item card's "also listed in" and move options compare the full transfigured name, so they don't list these rules for a transfigured gem.
