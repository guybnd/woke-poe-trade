## What broke

PoE refused the whole saved filter: `Line 331: Unable to parse parameter for BaseType rule: No base types found exactly matching "Dual Strike of Ambidexterity"`. Filters only know a transfigured gem by its base gem (NeverSink itself uses `TransfiguredGem True`), but the "gems in your build" rule copied the full name from PoB.

## Fix

- `gem-bases.ts`: `renameBases` swaps any transfigured gem in any BaseType list for its base gem (game data's `normalVariant`), without repeats, and marks the rule dirty so it is rewritten. `composeFilter` runs it last, over every rule (build rules, own rules, presets, edits, safety net), so no writer can bring the name back.
- Preview: `ItemFacts.filterBase` carries the base gem, and the matcher uses it for BaseType, so the card shows what the game will do with a transfigured gem.
