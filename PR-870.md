## What was wrong
In a Loot filter window resized taller, the Prices tab showed the first row of "Not moved" and then an empty band. Nothing was missing: the tab's scroll box was capped at `min(36rem, 70vh)`, so it ended partway down the window and the rest of the list sat below its own scrollbar. Prices, NeverSink, Presets, Gear, Preview and Build/Changes all had the same cap; only Rules grew with the window.

## Fix
- Those tab roots now use `flex: 1 1 <old height>; min-height: 0` (what Rules already does): the same size as before in a window that wasn't resized, filling it when it was.
- The Not moved "0 of 45 picked" count is plain text, not a category bar (it looked like a second heading).
- PR 860 (fake-price guard) isn't the cause: it doesn't touch the loot filter's spiked/crashed check (`economy.ts` `priceSwing`), and swapping a held price for its usual one can only make fewer items look spiked.
