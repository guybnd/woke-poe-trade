WOKEPOET-205, part two (cluster jewels), option A from the [mocks](https://claude.ai/artifact/LjV41JaacDXq9eFeQtrtTH): draw each cluster's tree.

- **Data:** `build-tree-data.mjs` now also writes a `clusters` block from GGG's tree export (outer sockets and their proxy groups, and the notables and keystones a cluster can add) and from PoB's `Data/ClusterJewels.lua` (MIT: templates, skills, notable sort order, orbit offsets). The tree file is rebuilt from the same 3.30 export. All 2,916 nodes are identical; the sprite sheets gain the cluster icons. `bump-data-version.mjs` was run, so it reaches players as live data.
- **Layout:** `cluster-graph.ts` ports PoB's `PassiveSpec:BuildSubgraph`:
  - socket, notable and small passes, including Medium's special rules;
  - orbit-index translation and orbit offsets;
  - links around the ring;
  - nested Medium and Small clusters in their sockets;
  - cluster keystones.
  Node ids follow PoB's scheme (0x10000 + socket index bits + size + index), so a build's saved points light up as in PoB.
- **Parsing:** items keep `Cluster Jewel Skill` and `Cluster Jewel Node Count`. The skill falls back to matching the enchant text, as PoB's ModParser does.
- **In the tree view:** cluster nodes join the tree for drawing, hover tooltips, Totals and search. Jewels inside cluster sockets show and count too.

**Checked against real builds:** across 47 tree sets in Guy's own PoB builds, every allocated cluster node id PoB saved exists in what this grows. That test only runs where a PoB Builds folder exists.

**Visual check:** I ran a throwaway e2e with Guy's wandler build (not committed). The large cluster with medium and small clusters in its sockets draws like PoB, with allocated paths lit.

Checks run locally: main tsc, renderer lint and vue-tsc, the test typecheck, build, unit tests (3,086 passed), and `pob-builds.spec` (14 passed).
