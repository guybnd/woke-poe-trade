## What

Guy asked for the AFK filter Net worth already uses to apply to nights, with the same "Leave out hideout" box.

- `story.ts` NightTracker reads the game's `AFK mode is now ON/OFF` lines (the same lines `net-worth/play-time.ts` uses). While AFK, chat and other lines no longer keep a night going, so 15 minutes AFK ends the night. A shorter AFK is cut out of the segment times (`afkMs`) and drawn as a gap in the strip, so death marks still line up with the clock. Segments now remember hideout/town (`hubMs`).
- `NightCard.vue`: played time leaves AFK out and shows an AFK total. It has a "Leave out hideout" box, stored on Session story's config (`nightWithHub`) so the dock card and Session analytics agree. Default leaves hideout out, like Net worth.
- Nights list, dock peek text and the Ctrl+Space tonight card use played time without AFK; Ctrl+Space shows the AFK row.
