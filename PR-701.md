## What

The four 3.30 Templar Vaults (Zealot's, Scholar's, Arkhon's, Machinist's) with their rewards priced from poe.ninja.

- **Data**: `npm run vault-data` reads the four poewiki vault pages (through `api.php`, the HTML pages are bot-blocked) and writes `public/data/league/vaults.json`, now a shared live-data file, so a league's changes reach players without a release. Reward lines it can't price are listed unpriced and the script exits 2 naming them.
- **Value**: GGG publishes no reward weights, so the "~typical pick" is an estimate: the expected best of four offers, rewards the wiki calls rare at a tenth the weight, unpriced rewards counted as 0. Gems priced at level 1 (the wiki gives no level).
- **Ctrl+Space**: "vault" (or "vaul", "templar vaults") gives an overview card and each vault's card; a vault's name opens it.
- **Nightmare maps**: Guy's Client.txt (Nov 4-21) shows 107 of 198 Nightmare runs followed by a vault (54%), always the map boss's quadrant vault (Fortress -> Zealot's 102/182, Abomination -> Arkhon's 5/11, Ziggurat -> Scholar's 1/2; Citadel and Sanctuary follow the same fragment-quadrant rule but weren't seen). The price check strip and the Nightmare search cards add chance x typical pick to each map's loot and profit, shown as its own part. Boss runs gets a "Vault %" setting and a line with the vault value (its own numbers are unchanged).
- **League checklist**: DEVELOPING.md gets a step to rerun `vault-data` and recheck the rate.
