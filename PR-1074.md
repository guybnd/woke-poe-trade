History rows used to read "Changed currency weights" dozens of times. Now:

- Each row says what moved, from what to what, and where: "Essences ruler · Normal 2.8c → 3.5c", "Divine Orb · price bias 0% → +25%", "Rare gear · score needed to show 4 → 6" (`history-words.ts`, worked out from each step's before/after, so old saved steps read the same way).
- Steps in a row on the same control within 10 min fold into one row with ×N; Back to here goes to the newest of them.
- Click a row to see every value it moved, and the trail of values for a folded row.
- Chips filter by tab (Loot, Equipment, Prices, Presets, Rules).
- A preset value changed again within 5 s grows the last step instead of adding a new one (`observe`), so a slider burst is one Undo.
- Item names get the item tooltip. NEWS line with a `history` spot; release-next-notes line.
- History moved into its own `HistoryList.vue` (lazy with the editor), so it doesn't touch the share-code block or the header.
