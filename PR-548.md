## What

On Alt+F, an unidentified magic Mind Cage said "✗ Hidden" (Rares to hide), but it showed in game. In 3.30, unidentified gear carries a drop tier, and the copy ends with `Unidentified (Tier 2)` (Guy's real copy is in the test). NeverSink's `gear->tiered` rules (`UnidentifiedItemTier >= N`) show it before the hide layer, but we never read the tier.

- **Parser:** `Unidentified (Tier N)` counts as unidentified and sets `unidentifiedTier`. Before, that line wasn't recognised, so the item counted as identified.
- **Item facts and matcher:** `UnidentifiedItemTier` is now judged from the copy. Identified gear has no tier and never meets `>= N`, as presets.ts already assumed.
- **Alt+F verdict:** when the rule we're sure of hides the item but a showing rule above can't be judged, the card reads **"? Probably shows"** instead of a confident "✗ Hidden".

- vue-tsc, eslint, build and perf budgets pass.
- e2e (loot-filter + price-check): only `stack sizes` fails, and it fails the same way on master. `preview drops` and the map verdict strip failed once under load and pass alone.
- An adversarial review found that identified gear would read "Probably shows". Fixed in the second commit.
