Ctrl+Space mod search reads a few words as filters. This is layout A from Guy's picks, with kind words, slot words and short names. Typo fixing was skipped.

- **Kind words:** "rarity vestig" lists only the Vestigial lines that have rarity. That's the 6 uniques: Aurseize, Goldwyrm, Greed's Embrace, Sadima's Touch, Wheel of the Stormsail and Wondertrap. "foulborn", "implicit", "explicit" and "can roll" filter the same way.
- **Slot words:** "rarity boots", "life ring" and "chaos resistance amulet" keep only that kind of item. The slot comes from the unique's base category. "weapon" covers every weapon kind.
- **Short names:** iir, iiq, ms, es, aoe, cdr, dot, ias, ci, eb, mom and rt. These work alone at 2–3 letters too.
- **Heading:** it names how the query was read, for example "Uniques with this mod · Vestigial · Boots".
- **Word pairs the mods have:** these stay mod text, so "energy shield" isn't read as a shield and "flask charges" isn't read as a flask.
- **Fallback:** when the filter reading finds nothing, the words are searched as plain mod text.
- **Cost:** about 0.5–5 ms per keystroke. The first query builds the word-pair set once, in about 20 ms.
- **NEWS:** a new line, `search-mod-filter-words`, with a Show me demo for "rarity vestigial". There's also a line in release-next-notes.md.
