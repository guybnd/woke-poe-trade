## What
- **Link:** atlas-blush-beta.vercel.app ("Atlas Tree Planner") links were never supported. Its hash is a compact bit-walk over the tree (0xa1 marker, BFS from the start, a bit per reached passive, 3 bits per picked type), plus older `id,id.v` lists and GGG codes. New `atlas/planner-link.ts` turns them into pathofexile.com links in the Import box, like hypostasis. The site's tree data is older than GGG's export (it lacks Celestial Presence 27261 and Runic Distortion 53484, which shift the walk), so links are read on the site's tree first, GGG's only when that fails.
