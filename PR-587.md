Saved lists parity, step 1 of 4 (WOKEPOET-364): Atlas strategies' list engine is now shared code, with Atlas on it. Regex library, Trade searches and PoB builds move onto it next.

## What
- **`shared/saved-tree.ts`** (pure, generic over where an item's folder lives):
  - nested folder tree, rows, moving items and folders on drop;
  - folder order, Alt+arrow targets, A to Z, path helpers.
- **`shared/use-saved-tree.ts`**: the list's behaviour from an adapter.
  - Ctrl / Shift picks (`selectPick`), drag and drop with marks and folded folders opening on hover, Alt+arrows.
  - One inline field for rename, move and new folder; fold / open, sort.
  - Hooks a list can set for what it can't do (`cantMoveFolders`, `cantReorder`).
- **`shared/SavedTree.vue`**: draws it. The list fills each row (`#item`, `#sub`) and its menus. Row keys are Delete / Backspace remove, Ctrl+C copy, F2 rename (`shared/saved-list` `rowKeys`).
- **Atlas strategies**:
  - `AtlasWindow.vue` uses the shared tree; `list-order.ts` and the folder helpers in `strategies.ts` now wrap it.
  - Behaviour is the same as before, plus Ctrl+C on a row copies the strategy code (as the menu's Copy, which now shows the key).

## Tests
- First commit: `saved-lists-2.spec.ts` pins Atlas's F2 rename, Delete + Undo, and Ctrl+C doing nothing (passes on master). The shared tree code passes Atlas's existing 39 unit tests (`atlas-list-order`, `atlas-strategies`).
- Then:
  - **`saved-list-parity.spec.ts`**: one set of checks to run on every list with the same items (folders fold, filter, F2, Delete + Undo, Ctrl / Shift picks, Alt+Down, drag into a folder, right-click menu). Atlas only for now; each list joins it as it moves.
  - Ctrl+C copies the code.
- Local (rebased on master after #586): vue-tsc, eslint, vitest 4419, `vite build`, e2e saved-list-parity, saved-lists-2, atlas-strategies, saved-lists, picks; perf: startup JS 1585/1640 KB, heap 19.6/21 MB, listeners 2259/2360.
- Review (independent pass): the drop line lost `z-index` and could hide under the next row (fixed); the picked list was reassigned on every content change (now only when one goes). Two harmless differences remain: a no-op Move no longer cleans a stored folder path, and Ctrl/Alt+Delete no longer removes.
