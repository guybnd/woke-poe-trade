Guy's picks from the mocks: **A** (edit in place) and **P2** (poe.re in its own in-app window).

## What changes
- **Rows:** a pencil and a bin show on the row under the mouse. The pencil opens the entry as a small form where the row was (name, string, category, tags, notes, hotkey, Exclude, length count). Enter or Save keeps it, Cancel drops it. The bin removes at once with Undo. The right-click menu gains Edit.
- **New:** a button next to the filter box opens an empty form at the top. It is filled in with the category you're filtering by, when that's a category.
- **poe.re:** "Generate on poe.re" opens poe.re in an overlay window (`woke-poe-re`, single, `menu::skip`, so no tab or launcher entry). The first time, it opens beside the library. "Save to library" reads poe.re's result box (`.rrb-result-text`), falling back to the clipboard. It suggests a name from the page heading and a category from the page (Maps, Vendor, ...), then saves through `saveToRegexLibrary`. There are also Back, Reload and Open in browser buttons. Old configs get the window added in `Config.ts`.
