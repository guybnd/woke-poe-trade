Guy's picks from the mocks: **A** (edit in place) and **P2** (poe.re in its own in-app window).

## What changes
- **Rows:** a pencil and a bin show on the row under the mouse. The pencil opens the entry as a small form where the row was (name, string, category, tags, notes, hotkey, Exclude, length count). Enter or Save keeps it, Cancel drops it. The bin removes at once with Undo. The right-click menu gains Edit.
- **New:** a button next to the filter box opens an empty form at the top. It is filled in with the category you're filtering by, when that's a category.
- **poe.re:** "Generate on poe.re" opens poe.re in an overlay window (`woke-poe-re`, single, `menu::skip`, so no tab or launcher entry). The first time, it opens beside the library. "Save to library" reads poe.re's result box (`.rrb-result-text`), falling back to the clipboard. It suggests a name from the page heading and a category from the page (Maps, Vendor, ...), then saves through `saveToRegexLibrary`. There are also Back, Reload and Open in browser buttons. Old configs get the window added in `Config.ts`.


## Review fixes
- Undo after a remove puts back only that entry, so edits, new entries and poe.re saves made in the meantime stay.
- The clipboard fallback only runs when poe.re's result box is missing. It only takes one-line text no longer than 250 characters, so it never offers item text.
- An entry open in the form stays listed while you filter, and an edit to an entry removed elsewhere is kept as a new entry.
- poe.re saves into the library window that opened it. Enter saves in the Save bar. The form's hotkey cell shows the reserved-key note.

## Perf budget
- The poe.re window and the edit form load only when first opened. One click listener on the panel serves New, poe.re and every row's pencil and bin.
- APT's dead Stash search widget, its editor and its hotkey code are removed. Config already moved its strings into the Regex library and deleted the widget on load.
- Startup JS (2211.2/2215), heap and listeners (2281/2300) are within budget.
- All JS is 4696.4 KB. The overage is entirely in the lazy chunks, so `bundle.allJs` goes from 4695 to 4700.
