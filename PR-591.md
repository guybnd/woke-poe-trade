## What

This adds a new pref, `gpuDrawing`, which is off by default. When it's on, the app skips `app.disableHardwareAcceleration()` and the overlay is drawn with the graphics card. That makes dragging and scrolling big windows smoother. It's the second half of the drag-lag fix, after #588.

- **Where to switch it:** in Settings > Install > Drawing ("Use the graphics card"), with a "Restart now" button. It's also a tray checkbox, so a user can switch it back if a GPU-drawn see-through window turns the game screen black (upstream issue #818).
- **Restarting:** the restart installs a downloaded update instead of racing it. Dev and portable builds don't restart themselves.
- **Reading the prefs file:** only boolean values are read now, so a hand-edited string can't turn a pref on.
