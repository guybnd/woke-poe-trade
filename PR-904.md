## What was wrong
In Session analytics' dock card, the "After a map" settings used a two-column grid (`auto 1fr`). The segmented option rows can't shrink, so the label column collapsed to its narrowest word: labels broke one word a line ("After / a / map, / show / its / time") and the options ran off the card ("Middle of the scr", "All the time in").

## Fix
- `ChipSettings.vue`: one column, each label on its own line above its control, a little space before each label; segmented options wrap to a second line instead of overflowing. Same component in Settings › Sessions, where the stacked layout reads fine too.
- New fake-game spec `chip-settings-layout.spec.ts` (in `scope.json`): opens the card's gear and fails if anything runs past the card's right edge or a label wraps. Fails on master (every label wraps), passes here.
