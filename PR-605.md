Guy's two pre-release picks for 1.330.10.

## Graphics-card drawing on by default

- `gpuDrawing` now defaults to true.
- Older prefs files saved every key, so a stored `false` is usually the old default. It reads as on unless the new `gpuDrawingChosen` flag is set. Any change of `gpuDrawing`, from Settings or the tray, sets that flag, so a player's own off sticks from now on.
- **Release note needed:** someone on 1.330.9 who turned it on, got a black game screen and turned it off has no flag yet, so they'll get it back on. The tray's "Draw with the graphics card" checkbox turns it off again.

## Old price snapshots trimmed to one point a day

- Snapshots past the 3-day window were only removed when their league saved again. Leagues no longer played kept hundreds of 1.3 MB files.
- A minute after start, each league keeps only these:
  - its newest snapshot;
  - the snapshots the 6 h and 24 h movers compare that newest one with;
  - the last snapshot of any day that has no day rows;
  - anything within the 3-day window.
- Day rows (one point per item per day) are untouched.
- A dry run on Guy's folder removes 392 files and frees ~450 MB (Allflame 185, Standard 207). Covens is untouched.

## Checks

- New tests: `testing/main/app-prefs.test.ts` (fresh install, old file, kept choice) and a trim case in `market-store.test.ts`.
- testing/main (250 tests) and main tsc pass.
- An adversarial review found two problems, handled as follows:
  - Movers for a league no longer saving lost their 6 h and 24 h comparison point. Fixed.
  - The black-screen case above. That one is kept, with the release note.
- Not run here: the CI Electron smoke test now starts with the GPU on under xvfb. Chromium normally falls back to software drawing there.
