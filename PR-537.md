## What

Follow-up to #525, from Guy's feedback on the ladder view.

- **Show from:** a picker above every ordered group's ladder ("Show from T16+"). One pick shows that tier and everything above it and hides everything below, folded rows included, as one Undo. It reads "Mixed" when the shown tiers aren't a clean top run.
- **The top tier stands alone:** it never folds into a band, so T16 always gets its own row.
- **Maps to hide as switches:** NeverSink groups whose rules all hide (Corrupted and Mirrored map hiders, shipped commented out) show as plain on/off switches with readable names ("Hide corrupted maps") instead of struck-through rows with a look editor. The side panel says what each one catches.
  - A `visibility` edit gains an optional `on` field: `true` uncomments the tier's blocks, `false` comments them out. Turning a switch back to NeverSink's state drops the edit.
  - Switch mode is decided from NeverSink's source, so hiding every tier yourself keeps the ladder.
