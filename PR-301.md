_Requested by **Guy**_

## Summary
- **Laggy drags in the layout editor (Shift+Space):** every mousemove wrote the widget's anchor, so Vue re-rendered the whole panel (its scoped slot) and the browser re-laid out and repainted it, while snapping re-measured every open panel. The drag now only shifts the widget with a CSS `translate` (once per frame, `will-change` while dragging), measures snap targets once at drag start, and saves the anchor on mouseup, or on window blur so a lost mouseup can't leave it unsaved.
- **Trade searches browser stuck over the game:** an open (non-live) search kept `invisible-on-blur` off, so it stayed on screen after the overlay closed but couldn't be clicked. It now hides with the overlay and comes back on reopen. The "Shift+Space to interact" hint is gone.

## Measured
Headless Chrome at 2560×1440 with Guy's config (Loot filter, Market, Trade searches open), 120-step drag of Loot filter:
- Event handling dropped from 225 ms to 16 ms; JS self time dropped from about 150 ms to about 5 ms.
- 90th percentile frame went from 12.5 ms to 4.4–8.3 ms.
- Drop position matched exactly (+480, +240).
