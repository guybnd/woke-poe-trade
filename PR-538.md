## What
In the PoE-mode price check, a picked influence mod (Crusader, Warlord, veiled, delve, essence, etc.) drew its icon on its own line above the mod text.

## Why
Tailwind's base CSS sets every `img` to `display: block`. The icon sits inside the inline `.w-poe-row-text` span, so the block forced a line break. Unpicked tooltip lines weren't affected because their container is `inline-flex`, and the corrupted diamond already had `inline-block`.

## Fix
`.w-poe-row-text > .w-poe-icon { display: inline-block; }`, so the existing `vertical-align` and margin now apply too.

## Checks
- New e2e test (Crusader body armour fixture) checks the icon and the first text line share a row. It fails without the fix and passes with it.
- `price-check-poe-mode` + `price-check-poe-first` e2e: 16 passed
- vue-tsc, eslint, vitest (4169 tests): all pass
- Adversarial review: the other `w-poe-icon` uses (FilterLinePoe, mercenary icon) sit in flex containers and aren't affected
