## What
In 3.30 the trade site moved granted skills and socketed supports to new ids (`explicit.effect_<n>`) with new words: the game now writes "Grants Level 22 Anger" and "Socketed Gems are Supported by Level 16 Added Fire Damage Support". It also renumbered four Foulborn support option ids and dropped others. 365 ids in `en/stats.ndjson` were dead, so price checks on those items either failed ("Unknown stat provided") or left the mod unread.

- `scripts/trade-data-patch.mjs`: new `remap()` runs before `diff()` in `apply` and `check`, and on its own as `remap`. It moves each dead id to the new id with the same stat text (ignoring "Skill"/"Support", a fixed level, and two renamed supports) and adds the new words as a matcher. The old words stay. It folds the stand-in stats PR #423 added for those ids back into ours, gives the renumbered Foulborn ids to the stat that now owns them, and drops ids with no replacement. Other languages' ids follow the English moves. The trade list is checked per stat kind, and the run stops if more than 500 ids would be dropped. A scoped run (`--group`) leaves ids alone.
- `scripts/upstream-data.mjs`: the hourly job's `apply` now does the remap first, so moved ids no longer come back as duplicates. It also reruns when only another language's stats changed, and its PR summary shows moves.
- Data, regenerated on top of #433: 251 ids moved, 4 renumbered, 66 duplicate stats folded, 114 dropped. Data version 9.
