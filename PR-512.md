**WOKEPOET-316.** Guy asked for build and character item tooltips as good as the price search ones. A rare or magic item from a PoB build or a character read now shows each prefix and suffix the way a listing does: P/S and tier in the margin, the tier's range beside each number, and the roll bar.

**Data:** `public/data/mod-tiers.json`, about 300 KB.
- Built by `npm run mod-tiers` from poedb.tw's 3.30 item class pages. RePoE is still on 3.29.
- Fetched the first time it's needed.
- Added to the shared live-data files, so players get updates without a release. `data-version.json` is bumped.

**Matching:** a mod line matches the mod on that item class that rolls the same words with the value in range. Ambiguous cases resolve in this order:
- A hybrid mod whose lines are all on the item takes them first.
- Then whole mods.
- At a range edge, the higher tier wins.

**No tiers shown for:**
- uniques, implicits and crafted lines
- jewellery with catalyst quality (the catalyst raises rolls past their tiers; catalyst quality is now read from both the site and PoB)
- ward bases

**Checks:**
- Typecheck and lint pass.
- vitest `mod-tiers`, `character-sync` and `live-data` pass.
- `vite build` passes.
- e2e `pob-builds` passes. Its tooltip assertion is updated for the tier display. The "picked loadout" test failed once in the full run and passed alone.
- An adversarial review found hybrid splitting, catalyst quality and live-data refresh problems; all fixed.
- Checked against Guy's real read: tiers look right on all his rares.
