This follows Guy's idea (2026-11-28): the section header decides for every jewel row, and a row only differs when you give it its own rule.

- **Jewels** and **Abyss jewels** start as **Always**. Each row shows at its set look ("Big", "Normal", ...) and its price reads "no price".
- Set the header to **By price** and every row without its own rule goes on the price ladder, using its guessed price and the ruler.
- Set the header to **Hide** and the whole section is hidden.
- Each row has a tick box, the same one Unique bases use, to hide just that row. A row's own step or price comes from its editor, as before.

How it works: `fixedOf(it, e, mode)` gives no set step when the section is on By price. `JEWEL_MODES` makes both jewel sections Always by default.

This replaces the per-row Always / By price / Off chip from the earlier commits, so `StateChip.vue` is back to what master has.

Tests: `filter-loot-jewels.test.ts` checks that the section on By price hides a cheap rare under a 1c line. `loot-filter.spec.ts` checks that the header starts as Always, that By price shows est. prices, and that Always brings the set looks back.
