Guy found it unclear how to turn off a jewel row that shows by default (rare jewels, magic and white jewels, and so on). Each jewel and abyss jewel row now has a tick box in front of its name, the same one Unique bases use.

- Untick it: the row is set to Off and those jewels are hidden.
- Tick it again: the row goes back to its fixed look.

The box only appears on rows with a fixed look, which today means only jewel and abyss jewel rows. It reuses the existing `toggleOn` helper, so there's no new logic.
