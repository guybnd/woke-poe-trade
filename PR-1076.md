Guy found it unclear how to turn off a jewel row that is always on: each row showed only "Big any". Now every jewel and abyss jewel row, the rows with a set look and no price, has:

- A tick box in front of the name, the same one Unique bases use. Untick it to hide the row; tick it again to bring back its set look.
- A state chip that reads **Always**, **By price** or **Off**. A click moves it along that order, and its hover says what each state does.
- The look beside the chip, shown as plain "Big" instead of "Big any".

The section header also counts these rows ("8 of 8 show · 8 always").

`loot-filter.spec.ts` checks the chip cycling on the Abyss jewels section and takes a snapshot of it. The section's mode chip still reads "By price"; the header redesign in #1071 covers that.
