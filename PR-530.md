## Why
Picking a unique in Ctrl+Space Search showed only its prices. Guy picked layout A in the [mockups](https://claude.ai/artifact/CiJymoeUrZeTS7AfebJKLF), plus five extras.

## What
Under the price table (it also shows for uniques with no price):
- **Mods**: variant chips when there are several. Lines every variant shares are dimmed, and the shown variant's price row lights up. If poe.ninja doesn't list a variant, it says so.
- **Foulborn**: each kind shows the mod it adds, the line it replaces (struck through) and its own price, with the range in the header. Picking a kind makes **Trade site** search Foulborn copies only. A Foulborn row's Trade site now adds that filter too; before, it searched the plain unique.
- **Vestigial**: the mod the unique leaves behind. This comes from the new `tips/vestigial.json` (395 uniques), built from Path of Building's `Vestigial.lua` and `ModItemExclusive.lua` by `npm run vestigial-data`. PoB parses with regex and never runs the Lua.
- **Facts line**: base, level, attributes, base defences and dust at ilvl 84. Uniques with restricted drops also get their source line.

The tooltip files load on the first unique you pick, not at startup. The data version is now 19, so if another data PR merges first, bump again.

Compatible with #526: the price table is unchanged, so the unidentified row slots in.
