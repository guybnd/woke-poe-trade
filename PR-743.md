## What

"Report an issue": a small draggable form (PoE frame, position kept) for a bug or an idea. It has a title, a text box, "Include app info" (on by default: version, OS, Electron, modules on, league), "Include recent log" (off by default) and a Preview that shows exactly what will be sent. "Open on GitHub" opens `github.com/guybnd/woke-poe-trade/issues/new` pre-filled, in the default browser. Nothing is sent and no token is used.

Where to find it:
- Settings › Install & updates › When something breaks › **Report an issue…** (find label added)
- Settings › About: the "Report a bug" link now opens the form instead of a blank issue
- Ctrl+Space: a **Report an issue** command, also found by report, bug, issue, feedback, github, idea

## How

- `ipc/issue-report.ts`: one pure builder (`buildIssue`) and `scrubText`, moved out of `main/src/woke/crash-reports.ts`. Crash reports (the "Report…" button on the crash notice) and the new form both use it.
- Scrubbing now also hides the PoE account name (with and without `#1234`) and the followed character, on top of the user folder, the user name and POESESSID. Everything attached is scrubbed, the title too.
- The link stays at 7500 characters or less. A long log is cut to its last lines and the whole scrubbed log goes on the clipboard, with "Log copied to clipboard, paste it here." in the body. If that's still not enough, the error texts and then the player's text are shortened. All cutting happens before encoding, so a `%XX` is never split. A ``` inside the log can't close the code block early.
- New op `issue-report` (preview or open), registered in `initWoke`, so the fake game has it too.
- The dialog loads only when first opened, so it stays out of the startup JS.
