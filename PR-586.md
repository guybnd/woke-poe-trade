_Requested by **Guy** · [project thread](https://claude.ai/code/project/chan_01TFAVQEVFL8KKQ8fhVfpfJo?thread=cmsg_01TFAVQEVFL8KKQ8fhVfpfJoJdgbnRpfJRNXzkcsH2vjR7)_

The Covetous Dark (3.30) showed 4 explicit lines as "Not recognized modifier". This affected in-game copies and pastes alike, because the stats were missing from the data:

- **"Gain a random Shrine Buff for # seconds when you Blind a / non-Blinded Rare or Unique Enemy"**: `trade-data-patch.mjs` skipped every trade stat whose text wraps over two lines. It now adds them as new stats. Rewordings still only take one-line texts.
- **"Attacks with this Weapon have #% chance to deal Triple Damage"**: the trade site added this stat after our last refresh.
- **"Blind Enemies on Hit"**: this is how the game writes a 100% chance. The new `certainChance` step gives every non-map "#% chance to X" stat an "X" matcher worth 100, unless some stat already has those words. If the trade site later adds a real stat with the same words, it gets a stat of its own and the 100% matcher is removed.

Data refreshed with `apply`: 154 new stats, 33 new ids on known stats, 5 items, and 199 100% chance texts. Enshrouded Quiver now has its Quiver category. Data version 21.

Checks:
- An adversarial review parsed 17,345 matcher lines and all 42 fixtures with the old data and the new: no difference. A structural scan found no shared matchers and no line stealing. Its two minor findings are fixed.
- Lint, test typecheck and the full vitest run pass (4409 tests).

Known gap: stats tagged as map mods don't get the 100% text, because the map mod list would pick it up. Global "Poison on Hit" is one of them, so it is still not recognised, same as before this PR.
