## What
- **Market** is now a poe.ninja-style price list: every category in a side list with item art (poe.ninja's groups and order), filter box, c/div, sortable Name / Value / Last 7 days, and poe.ninja's own 7-day line and % ("Not enough data" when it has none).

- The old window keeps movers, watchlist and alerts as **Movers**, opened from a button on the Market title.
- One-time config step (woke version 2): adds the Market window just before Movers on the rail, renames a default "Market" title to "Movers" (a custom name stays).

- New widget type `woke-market`, lazy-loaded.
