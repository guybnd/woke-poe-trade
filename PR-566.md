_Requested by **Guy** · [project thread](https://claude.ai/code/project/chan_01TFAVQEVFL8KKQ8fhVfpfJo?thread=cmsg_01TFAVQEVFL8KKQ8fhVfpfJoA43NKqXWifoYTB4Gd8EcWG)_

Guy's settings file had grown to 1.1 MB. 97% of it was the loot filter editor's undo steps (`timeline`) and save points (`history`). The settings file is sent to main and written whole on every save of any setting, so every overlay close paid for that. This PR moves the history into its own file. What you see doesn't change.

## Changes

- **`history-file.ts`:** the undo steps and save points live in `<userData>/woke-docs/loot-filter/history.json`, through the doc store. The file is written 1 s after a change settles, when the widget unmounts, and before quitting. Main now also waits for document writes on quit (`docWritesDone`).
- **Migration:** on first start, the old fields move into the file and are only taken out of the settings once the write succeeds. If an older copy of the settings brings them back (the Settings window saves its own copy), the file wins and they're dropped again.
- **Safety:**
  - A new `doc-get-strict` op reads with `readJsonStrict`. A history file that's locked right now is never written over in that run.
  - A broken file is moved aside, and the editor starts over from what the settings held.
  - Changes made before the history has loaded wait for it.
- **Trim:** the undo list is capped at 500 KB instead of 1 MB. That's still dozens of ordinary steps; only steps with large price applies drop sooner. The parsed source copy behind the step labels (`sourceDoc`) is now released after 30 s idle instead of being held for good.
- The widget config keeps `timeline?` and `history?` only as legacy fields, for the migration.

## Measured

Guy's real config, booted in the fake-game harness:

- The settings file goes from 1.1 MB to 50 KB after migration.
- The history file holds 37 steps and 20 save points.
- Blurring the overlay (which saves the settings) no longer makes a long task. Before #563 it took 101-145 ms, and 58-67 ms after it.
