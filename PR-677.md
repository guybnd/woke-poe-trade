Each captured beast now shows its Bestiary group and family, so you can tell which beasts to prefer while hunting.

- League Mechanics › Bestiary: a faint tag after each name, e.g. Craicic Croaker "Amphibian · Deep" (layout A in the mocks).
- Ctrl+Space beast page and result row: "Beast · Amphibian · Deep".
- `mechanics/beast-kinds.ts` holds all 221 captured beasts in the item data, by group. The data comes from poedb's monster pages (game data). Each group belongs to exactly one family. Genus is left out because poedb's genus field disagrees with the wiki's.
- Test: every CAPTURED_BEAST in `items.ndjson` has a kind, so a new league's beasts fail the test until they're added. The lookup ignores accents (Black Mórrigan).
