_Requested by **Guy**_

Removes the Heist gem OCR feature, which is no longer used.

- **Gone:** the hotkey (`ocrGemsKey`, `ocr-text` action and IPC event), `HeistGemFinder` and the worker's `findHeistGems`, the Shortcuts OCR worker, the `apt-heist-ocr` module (so it drops off the settings, Screen reading page and landing module list), the mechanics guide link, the i18n key, and the unused `settings-item-search.vue`.
- **Kept:** the shared OCR worker for map scan, essence scan and death recap. It no longer loads `heist-lock.bmp`.
- **Item-search widget:** reduced to an empty shell, since the OCR was the only thing that put anything in it. It stays so saved configs and its tab (which opens the search palette) keep working.
- **Dependencies:** drops `fastest-levenshtein` and `@wokwi/bmp-ts`, which nothing uses any more.
- **Docs:** README, DEVELOPING and the OCR guide no longer mention the feature.

Old configs keep a harmless `ocrGemsKey` or `apt-heist-ocr` entry, and nothing reads either one.
