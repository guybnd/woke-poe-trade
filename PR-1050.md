## Bug
`CurrencySettings.off` was one list for every Loot page, so unticking Show on Normal under the Currency ruler hid Normal on Uniques, Gems, Cards and the rest too.

## Fix
- `off` → `offBy: Record<string, number[]>`, keyed by a class page (`currency`, `uniques`...) or a section id. `stepsOffIn(c, cat)` = section's own, else its page's. `offSteps` uses it.
- Old saved `off` migrates to `offBy.currency` (where it was set).
- Ruler step card: "Show in all currency" (per page), with "N sections set their own".
- Each section body gets a **Steps** row (Small/Normal/Decent/Big checkboxes, "as the ruler" or an undo).
- StateChip bias menu: "Price bias, whole section" and "Every item here counts at…", so section vs item scope is clear (item scope is Alt+F's Worth × / own price).
- Defaults clears this page's and its sections' steps only.
- NEWS line `loot-filter-section-steps` with a Show me spot on Orbs' Steps row; release notes line.

## Tests
Unit: offSteps scoping + migration; existing off tests moved to `offBy`. e2e: Orbs Steps row toggle + undo. Local: vue-tsc, eslint, filter-*/news/help unit tests (2727 pass).
