Saved lists parity, step 2 of 4 (WOKEPOET-364): the Regex library moves onto the shared saved tree from #587.

## What
- **Regex library**: the list is now `SavedTree`, as Atlas strategies:
  - nested folders from each string's category ("a/b") that fold; drag reorder of strings and folders; Ctrl / Shift picks; Alt+arrows;
  - F2 rename in place; Move to folder; New folder; Delete (one or several) with Undo; the filter;
  - a folder menu: new string here, new folder inside, rename, move, A to Z, fold / open all, remove folder with Undo.
- Kept as before:
  - a plain click (or Enter) on a string searches the stash;
  - the pencil opens the edit form in place of the row; bin and copy buttons;
  - the New form at the top. A new string goes in the folder of the string you last clicked, or the folder you chose in its menu.
- **Locked folders**: "Atlas strategies/…" and "PoB builds/…" belong to those tools, which file regexes by name. They can be reordered, but not renamed, moved, removed, or have folders moved into them; a note says why.
- New optional settings: `folders`, `folderOrder`, `closedFolders` (as Atlas).
- **Shared code**:
  - `SavedTree` gains an `open` action on plain click (once per double click), an editor slot, an actions slot, row tooltips and an optional second line.
  - `shared/saved-list` gains `removeEntries` (several at once, Undo puts each back where it was).
  - Rows now share one listener per event (perf).

- F2 renames in place (#585 made it open the edit form; the pencil still does).
