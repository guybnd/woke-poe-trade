_Requested by **Guy**_

The iLvl box (and every other numeric filter box in the price check header: links, quality, gem level, map tier, sockets, stack size) started a drag from anywhere you pressed, so clicking it to turn the filter on or off only worked on the small label.

- Only the numbers start a drag (cursor `ns-resize` on them). Clicking anywhere else in the box toggles the filter (cursor pointer).
- A press that began on a number never toggles, even if released on the dash or label.
- Toggling uses the state from the start of the press, so clicking off a box with an emptied min (which disables on blur) still switches it off rather than back on.
- The box is focusable with Enter/Space to toggle, replacing the old label button.
- Wheel anywhere in the box still nudges the value.
