After #740, Trade site worked for Cortex but price check still found nothing.

**Cause:** a unique priced without game text (from Ctrl+Space or an item menu) is a virtual item that isn't corrupted, so the price check searched `corrupted: false`. On the live trade API, every Cortex listing is corrupted: in Covens, `corrupted: false` gave 0 results and no filter gave 1,669. Replica Cortex was the same (0 vs 192). Other unique maps such as Mao Kun aren't affected.

**Fix:** `virtualUnique` marks Cortex and Replica Cortex as corrupted, so the corrupted filter is "any". That matches what a real in-game copy (which reads "Corrupted") already does. A unit test covers both and checks that Mao Kun still searches uncorrupted copies.

An adversarial review found no bugs. It noted one comment out of place, which is now fixed.
