Saved lists parity, step 4 of 4 (WOKEPOET-364): PoB builds move onto the shared saved tree (#587, #590, #594), so all four lists now work the same.

## What
- **The list** is `SavedTree` over the builds folder's files:
  - nested folders (a build's folder on disk) that fold; Ctrl / Shift picks; Alt+arrows; F2 rename; Move to folder; New folder; Delete (one or several, one Undo); the filter;
  - a folder menu: new folder inside, rename, move, A to Z, fold / open all.
- **Order kept in the app** (Guy's pick):
  - The order you set is saved in settings (`buildOrder`, `folderOrder`; a "My order" sort, which drag and Alt+arrows switch to); files stay as they are.
  - A build saved in PoB since goes after the ordered ones, by name. Deleted builds drop out; renamed or moved builds keep their place.
  - Latest save first (pinned first) stays the default sort; the new button in the title switches between the two.
- **On disk, only when the folder changes**:
  - A build moved to another folder moves its file (as Move did).
  - A folder renamed or moved moves on disk through a new main call, `pob-move-folder`. Every build's settings, pins and regexes follow, with Undo.
  - Guards: never into itself, never over a folder that exists, never deeper than the list reads; a case-only rename works; a name is cleaned as the disk needs and the list follows the cleaned name. A folder that's only in the list just changes in the list.
- Kept: a click shows the build; P pins; the pin button; Delete only (not Backspace), as before.
- `testing/fake-host` Electron stub gains `shell.trashItem` (Delete in e2e).

## Behaviour changes
- Pinned builds sort first inside their folder; there's no separate Pinned group across folders any more.
- Folders open or fold as you left them (remembered), instead of opening the latest league's and the build in use's.
- Leaving the name field now keeps the new name (as in the other lists); before, it cancelled.
