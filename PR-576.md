## What
- **`ui/WItemRow.vue`**: one item row. Art, game tooltip on hover, item menu on right-click, and one left-click: `price-check`, `trade`, `pick` (the list's own action) or none. Layout stays the list's (class + slot); `as="tr"` for table rows.
- **`openPriceCheck(ref, at, info?)`** in `ui/tooltip/item-price-check.ts` (plus `dispatchPriceCheck`, `cursorPoint`, `elementPoint`) replaces the copies in the item menu's Price button, Search's Live listings, PoB build gear and the price check side window. **`openTrade(ref)`** is the item menu's Trade, now shared.
- **`itemArt(ref)`** in `ui/game-icons.ts`: one art lookup (poe.ninja type, else item/unique/gem/card by name). Search lookups use it; `lab-gems/icons.ts` now delegates to `gameIcon`.
- **One "uniques on this base"**: `shared/uniques-on-base.ts` (`uniquesOnBase`, `basesOfUnique`, the index) used by Search and the loot filter, and `shared/UniquesOnBase.vue` drawing both Search's base pane and the Alt+F card's "Can drop as".
- Lists moved onto the row:
  - Side window: tooltip and menu now use the row's own item (English name, kind, base), like its click. Before, it looked up the shown (translated) name.
  - Gem versions: rows get the gem's tooltip and menu for that version; "Click to search this version" moves from the native title into the tooltip.
  - PoB build costs: unique rows get tooltip and menu; the menu's Price and Text use the build's own copy.
  - Alt+F "Can drop as": art, tooltip, menu (was plain text).
