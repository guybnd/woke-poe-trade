## Bug
With the Currency farming goal, a map with no More Currency got a More Currency tile turned on at ≥1, so the trade search only found *other* maps with More Currency. Same for Maps & Threads (More Maps / More Threads). Cause: `applyGoal` turned the goal's wanted More X extras on (added 2026-11-25 so the tile shows up).

## Fix
- A goal's More X tile still shows, but **off** ("–", dashed, no min box, not in the query). One click turns it on at min 1.
- Picking a goal no longer turns any extra on; it only turns off the More X ones it doesn't want.
- Farming templates turn an extra on only if it was added with + when saved. Templates saved before this (no `extraV`) skip extras at min 1, since the old goal may have turned those on by itself.
- Scrolling over an off extra tile no longer turns it on.
- Drops / Rarity / Pack / Div cards extras: never turned on without a click (checked).
