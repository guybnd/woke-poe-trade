The loot filter's sound picker (and the Preview tab's sound buttons) now play the game's own alert sounds, `PlayAlertSound` 1-16 and the named ones (ShAlchemy, ShBlessed, ShChaos, ShDivine, ShExalted, ShFusing, ShGeneral, ShMirror, ShRegal, ShVaal). The Sh ones are new in the picker. Before this, game sounds said "play only in game".

## How

- The sounds aren't in the bundles: they are loose FMOD banks at `<install>/FMOD/Desktop/ItemFilter.bank`, an FSB5 of Vorbis samples `AlertSound_01..16` and `SH22Alchemy..Mirror` (event names `event:/Sound Effects/Misc/ItemFilter/AlertSound_NN.ogg`).
- FSB5 Vorbis needs FMOD to decode, so `main/src/woke/game-sounds.ts` runs a small PowerShell script (Add-Type C# P/Invoke) against the install's own `fmod.dll` with no sound output, and writes 16-bit WAVs into `userData/game-sounds/<install>-<size>-<mtime>`. About 1.5 s, once per game patch; only a full set of 26 is cached.
- The install comes from the running game, then every Client.txt on the PC.
- New op `filter-game-sound` returns one WAV as base64. Ids are whitelisted.
- Nothing of GGG's is shipped or committed.

## Tests

- `testing/main/game-sounds.test.ts`: the id map, FSB5 slicing, and (only where the game is installed) a real decode with the game's FMOD. Passed locally against FMOD 2.3.11.
- `renderer/test/woke/filter-preview.test.ts`: which ids can be previewed.
