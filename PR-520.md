## What
- **Viscera in Market › Prices**, matching https://poe.ninja/poe1/economy/covens/viscera: poe.ninja's dense feed has type `Viscera` (~530 rows), but the app dropped it as an unlisted category over the 500-row cap. It is now a listed category (`CATEGORY_TYPES`), under General. Each effect shows on a line under the name.
- **Item art**: the game data has none for Viscera yet. `npm run ninja-icons -- <league> [Type…]` saves poe.ninja's art to `public/data/league/ninja-icons.json`: shared live data, data version 18, read lazily by `market/ninja-icons.ts`. The search palette uses it too.
- **League Mechanics › Covens** sections (Head/Torso/Upper/Lower/Other Viscera) now fill. They take type `Viscera`, match any tier (Lesser/Greater), and show each name at its cheapest effect (a tip says so).
- **Tooltip**: hovering a Viscera lists all its effects with their prices, most valuable first, with the hovered one lit. Long names in League Mechanics wrap instead of being cut.
- **Thin markets**: poe.ninja began tracking Viscera today, two days into the league, so 362 rows priced on every tracked day read thin, and Skip low confidence emptied Covens. A category tracked for fewer days than the league now counts its own days, and a row with no history yet isn't thin. This changes one #518 expectation in market-gaps.test (noted there).

Other modules can read Viscera prices with `usePoeninja().findPricesByName('ITEM', name)`, with no new fetch. Wickerman's #519 depends on this PR.
