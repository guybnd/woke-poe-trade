Fix for #875: on a map price check, "Cards that give it" listed The Encroaching Darkness. Every map is checked as "Map", and that card's reward is `<uniqueitem>{Map}`, which means any unique map.

`cardsFor` now matches a card only when its reward tag fits the checked item: a unique for a unique, a currency for a currency. A separate review ran a script over every card in tips/items.json: no false positives are left and no real card was lost.
