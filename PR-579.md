## What
- **`shared/picks.ts`**: one Ctrl/Shift rule for every pick list.
  - `togglePick`: a click or Ctrl+click toggles one and keeps the rest; Shift adds the run from the last click. Used by loot filter chips (`groups.ts pickBases`, so the filter editor and the Alt+F card), the Gear tab lanes (run within the lane holding both), and the Prices tab check boxes (`picks.ts usePicks`, via `runOf`).
  - `selectPick`: file-list rule for Atlas strategies (click opens one, Ctrl picks more starting from the open one, Shift picks the run from the open one).
- **`loot-filter/tier-move.ts`**: `useTierMove` gives the filter editor and the Alt+F card one move: one undo step for the lot and the same "Moved …" note. The editor still follows the items to their tier; the card still names tiers as its rows do.

- The Alt+F card's one-row "move it here" buttons keep their direct edit (no note), as today.
