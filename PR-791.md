## What
Guy picked A + C on the [mockups](https://claude.ai/artifact/Fzrunv53XND8k44SE6tS1Q):
- **Per group: Open / Folded / Off.** Open shows every row, Folded shows the top 3 with a "+N more" row (click or Enter opens the rest, its first new row is picked), Off leaves the group out with a "N groups off · show" row at the end. Every group starts Folded. Answer, Prices, Uniques on a base, Recent and Things to try are always full. In a folded group, rows whose name starts with the query go first.
- **Chip row** (All · Prices · Items · Facts · Tools · Settings · Web, with counts). A chip shows its groups in full, off ones too. Ctrl+Left / Ctrl+Right step through the chips. A new search starts on All.
- **Where to set it:** a cog in the search bar swaps the results for the list, and Settings › General › **Search (Ctrl Space)** has the same list. The search hotkey's link now points to that page. Ctrl+Space finds the page ("what search shows").
- Saved on the search widget as `groups`, holding only the changes from the defaults.
- Jumps to a row inside a folded group (a beast's recipe, an answer) open that group first.
- Also fixes a tooltip gap found while counting: the currency conversion heading in the detail pane had no item tooltip.

Background: across 57 everyday searches, the spam came from long groups, not unwanted ones ("chaos" gave 15 groups and 39 rows).
