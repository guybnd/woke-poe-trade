Guy's bug (Gigafarm profile, live dev): Equipment › Base ranks showed every base as "Unranked (trash)", with 0 in Rank 1-3 and Exotic.

## Cause
- `readTiered()` returns null when the filter has no NeverSink `gear->tiered` rules, which is the case on our own base. The Base ranks lanes came only from it.
- `exoticBases()` read only NeverSink's `exoticbases` rules.

## Fix
- `rankSource(doc)` returns NeverSink's tiered rules when they're there. Otherwise it returns our base-ranks.json ranks with no cells. GearTab and GearRankStrip now use it.
- `exoticBases(doc)`: with no NeverSink exotic rules, it uses our table's x1 (valuable) and x2 lists.
- Test: on `ownBaseText`, the rank lanes match base-ranks.json and every exotic is listed.

The "Your table replaces N of NeverSink's gear rules" text and the Back to NeverSink link are left to the M7 thread.
