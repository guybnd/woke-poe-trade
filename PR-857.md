Follow-up to #828 (WOKEPOET-523). Guy: the map Exchange view showed a wrong banner, and the rows couldn't be clicked to whisper, so the view did nothing useful.

- **Banner**: TradeBulk showed "available on the Currency Exchange Market" for every bulk item. It now shows only when `item.info.exchangeable`, as TradeListing already does. Maps aren't, so it's gone there; currency checks keep it.
- **Whisper**: the exchange API returns a whisper template per listing (`listing.whisper` with `{0}` item and `{1}` pay, plus per-offer `item.whisper` and `exchange.whisper`, in the seller's language). `toPricingResult` keeps those parts; `bulkWhisper(row, lots)` fills them. Clicking a row (not yours, not the market-ratio row) sends it with `paste-in-chat`, the same path the Trades widget uses for replies. A Buy box in the toolbar sets how many to ask for. That's rounded up to the seller's lot size and capped at their stock; it starts at the item's stack size (1 for maps). A short "Whispered <name>" note confirms the send. The row's hover shows the exact text.

Applies to every bulk check, not only maps (currency rows can be whispered too).

Tests: unit test for `bulkWhisper`; the map e2e checks there's no banner, then clicks a seller with Buy 10 and checks the exact whisper sent to main.
