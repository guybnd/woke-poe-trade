A user (installed build) set the dock's notification icons to **Always** hidden, and every update they came back. Cause: hiding the What's new icon only hid the icon. Each update's new NEWS lines still put NEW seals in All tools and a count on the rail, because `seenNewsIds` only respected `newsOff`.

Changes
- `newsIsOff` (news.ts): What's new counts as off when switched off **or** its dock icon is hidden for good. Used by seals/count (`seenNewsIds`), Worth knowing (WokeOverlay, WhatsNew) and the Settings switch.
- Hiding What's new (right-click › Always, or Icon row Show) marks every line seen, like switching it off; Undo puts `seenNews` back.
- Switching "What's new after updates" on un-hides the icon.
- An icon folded into a hidden host (Lab gems into Lab) stays hidden when it shows later on its own (`iconHiddenIn`).
- Config upgrade, settings merge and ConfigStore checked: none touch `woke.dock`.
