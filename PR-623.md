## What
Net worth's item table: **Share** used to be a bar scaled to the biggest row, so the top row always looked full. Now it is each row's real percent of the whole net worth, with the % shown as text beside the bar (`12%`, `3.4%`, `<0.1%`, hover says "of your net worth").

The total is the whole valuation (`Valuation.chaos`), so the % stays the same while category, tab, search or value filters change. Unpriced and ignored rows still get no bar.
