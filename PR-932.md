## What
The character's Live build (`Builds/Live/<name>.xml`) wrote jewels without a `Radius:` line. PoB only gives a jewel a radius from that line (Item.lua `specName == "Radius"`), so timeless jewels such as Elegant Hubris, and Thread of Hope, did nothing in that file.

- `worn-items.ts`: reads the API's `Radius` property into `PobItem.radius`.
- `live-pob.ts`: `pobNativeText` writes `Radius: <label>` before `Implicits:`.
- `character-sync.ts`: snapshot version 3. On load, a version 2 read is rebuilt from the saved replies so existing Live files pick up radii without waiting for a new read. If it can't be rebuilt, it's kept as it is. The rebuild code is shared with the version 1 path.
- `claude-link/tools.ts`: accepts version 3.
