## What

For WOKEPOET-366 (Guy picked option C, with typing to filter).

On a non-unique cluster jewel, the price check title becomes a size and type picker:
- Typing filters the list.
- Picking an option rewrites the search as that jewel would read: base type, enchant row and passive count.
- Notables from the old type are unticked. On Small, the small-passive effect row is unticked too, since Small never rolls it.
- Picking the copied jewel's own size and type puts every tick and box back, including a legacy type the trade site no longer lists.
- The title's Generic/Base switch moves to a "This size / Any size" chip.

Picking never starts a search; the Search button still does.
