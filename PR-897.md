## What
Discord bug report: after a search, clicking **Low** under a mod ran a new trade search right away. Clicking it on several mods quickly ran into the trade rate limit.

`RollPick.vue` (the Low / ≈ / High buttons under each mod) used to call `price-check-search` on every click. Now a pick only sets the range, the same as typing in the min/max boxes. The existing stale logic in `CheckedItem.vue` takes it from there: the results dim, or filter in place when the range got tighter, and the Search button shows. No new UI.

The Low / Approx / High presets for all mods above the list still search, since that's one click for every mod.
