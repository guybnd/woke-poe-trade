## What

Guy's follow-ups after trying the Megalomaniac searcher (#617):

- **Tools menu:** the searcher is a normal tool under Builds & trade.
  - The module entry is listed in the README and the Tools help.
  - The Mapper, Leveling and Trader presets include it.
  - Old configs lose the hidden flag.
  - Opening it from a build page turns the module on if it's off.
  - The Ctrl+Space card only shows while the module is on.
- **Tooltip:** each mod of a notable is on its own line. The help card got an opt-in `lines` option for this.
- **Save:** a bookmark button next to Search saves the search to Trade searches, using the same name-and-folder box as the price check.
- **Must-have notables:** right-click a notable to make it a must-have, up to 3, shown with a gold lock.
  - Must-haves go in an `and` group.
  - In Count mode they count toward "need", and the count group covers the rest.
  - In Weighted sum mode they also add to the total.
  - The whole query stays within the trade site's 35 filters.
- **Filter:** it also matches mod text. Matches outside your tags get their own "Other matches" group.
- **Sellers:** the search uses the price check's listing setting (Instant buyout by default) instead of the link helper's In person (online).
