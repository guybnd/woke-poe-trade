_Requested by **Guy**_

Guy asked for the "Added Small Passive Skills also grant: +X% to Fire/Cold/Lightning Resistance" lines on cluster jewels to work like pseudo resistance, the way resistances do on other gear.

## What changes
- A cluster jewel with exactly one of these lines gets a **total Elemental Resistance** row. The "all Elemental Resistances" line counts three times. The row is ticked, and the line's own row is unticked under it.
- The trade site's pseudo totals don't count cluster lines. On Allflame, a cluster Fire line found 10,000 items, but the same search plus `pseudo_total_fire_resistance >= 1` found 0. A weighted sum would add them up, but without a trade login it's refused as "Query is too complex". So the row searches **any one of the four lines** at the total, with all-res at a third.
- With one line on the item, that is the same as the total. Jewels with two resistance lines are left as they are, because one line at a time can't add them up.
- `{div_by_N}` trade id prefixes now accept any N (previously only 100).
- Stat columns read a listing's total from the same lines.
