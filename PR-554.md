Theme every plain control left in the overlay (WOKEPOET-340). A scan of every template found browser-drawn parts next to the PoE 1 art: blue checkboxes and radios, blue sliders, plain dropdown arrows, field boxes that skipped the well look, and pill buttons.

**Shared, so new windows get it too** (game look only; Modern and Classic keep theirs):
- `controls.css`: native checkboxes, radios and sliders inside any toolkit window (`[data-w-panel]`, `[data-w-settings]`, `[data-w-window]`, `.w-surface`) become recessed wells with a gold tick, dot or bronze handle; `.w-select` and Settings dropdowns get a gold arrow. Hidden inputs (`.sr-only`) and the loot filter editor's own switches (`[data-w-switches]`, #553) are left alone.
- `poe-options.css`: with PoE 1/PoE 2 art on, those checkboxes take the game's checkbox coin and every slider (not only Settings) takes the art track and copper handle.

**Per window:**
- Fields and dropdowns that copied the plain field look now carry `w-input` / `w-select`: Boss runs, Farming, Sessions, Atlas strategies, loot filter rule builder, style editor, sample card, stack size box, path fields, rail rename box.
- Pills and one-off chips use `.w-chip`: rail layout popup (theme row now 3 + 3, no more "PoE / 1" wrapping), loot filter Shown/Hidden/Turn on, dock menu dismiss chips, PoB "Mine".

APT core files are untouched. The price check keeps its own PoE mode look.
