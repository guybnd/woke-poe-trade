Guy asked for two things on the map price check:
1. Nothing Sentinel-related should be marked by default.
2. An Evocator mod should match any of the three Evocators by default.

- **Sentinels**: already guaranteed. A rare map's own mods (`mapMod`) start Any, and the bulk preset leaves them out. This PR locks that in with a unit test and an e2e test, using a T16 Originator fixture that has a buried Stalker Sentinel and an Evocator.
- **Any of three**: `mapModFamilies` (pseudo/maps.ts) gives an Evocator map mod the tradeIds of all three Evocators (Beidat, Ghorr, K'Tash), so Has sends a count group (min 1) and Not leaves out all three. The same goes for the three buried Sentinels. It keeps `anyOf.exact` so the strip can narrow back.
- **Map strip**: the row gets a small "any Evocator" / "this one" chip that switches between the two.
