Part 1 of the security audit fixes (items B and G).

**Webviews and links (`main/src/woke/web-guard.ts`)**
- `will-attach-webview`: strips any preload, forces Node off (incl. workers and subframes), context isolation, sandbox, web security on; refuses a non-web `src`.
- Inside a webview: popups stay blocked (as before), and a navigation to anything but http(s)/about:blank is cancelled, whether it came from a link, a redirect or the overlay setting `src`.
- Permissions: sites in a webview get only copy-to-clipboard and fullscreen; the overlay's own page keeps notifications.
- The app's own windows can't be navigated off the app's page; such a link opens in the browser.
- Every `shell.openExternal` from a window-open goes through one http(s)-only check, so a `file:` or protocol-handler link can't start a program.

**Crash reports (`crash-reports.ts`)**
- The pre-filled public GitHub issue replaces the Windows user folder (either slash, any case), other `C:\Users\<name>` paths and the bare user name with `~` / `<user>`.
