One-off features audit, finding 7 (WOKEPOET-363), first step: the shared parts, with Regex library and Trade searches moved onto them.

## What
- **`shared/saved-list.ts`**:
  - `rowKeys({ remove, copy, rename })`: one row key rule. Delete (or Backspace, as before) removes, Ctrl+C / Cmd+C copies, F2 renames.
  - `removeEntry(list, id)`: removes one entry; its `restore` puts back just that entry where it was, keeping changes made since, under a fresh id if one was taken.
  - `useDraftName(root)`: one inline name field at a time. It focuses with its text picked; `finish` returns the trimmed name once.
- **Trade searches**: row keys, removal and renames (entries, folders, new folder) use it.
- **Regex library**: row keys and removal use it.

## Behaviour changes
- F2 on a Regex library row opens its edit form, as in Trade searches. The menu's Edit now shows F2.
- Trade searches' Undo puts back only the removed search. Before, it restored the whole list as it was, which dropped renames or moves made after the removal.
- Ctrl+C on a row ignores Ctrl+Shift+C and Ctrl+Alt+C, and also works with Cmd.

## Left for later (the rest of the finding)
- Atlas strategies and PoB builds keep their own lists for now. Atlas already has folders, drag, multi-select and Alt+arrows; PoB builds are files on disk.
- Moving them, and nested folders / drag reorder for Regex library and Trade searches, are the next steps. Want a follow-up ticket for that?
